────────────────────────────────────────────
광택도 : G2b – 실크광(반광)
습윤 마모 : R-등급 1 (DIN EN 13300)
은폐력 : H10-등급 2 (도포율 7 m²/L 기준)

재료 기반 : 합성수지 분산형 도료
소요량 : 1회 도장당 약 140 ml/m² (평활면 기준)
색상 : 백색, 올드 화이트 10 (RAL 9010에 해당)
포장 규격 : 12.5 L

⑥ 본문  (제품 설명)
────────────────────────────────────────────
같이 드린 "latex-gloss-60-body-blocks.txt" 를 쓰세요.

  1. 편집 화면 **오른쪽 맨 위, [저장] 버튼 바로 옆의 ⋮** 를 누릅니다.
     ★ 본문 안쪽에 뜨는 작은 ⋮ 가 아닙니다. 화면 제일 위쪽 ⋮ 입니다.

  2. 메뉴에서  [편집기] → [코드 편집기]  를 고릅니다.
     (단축키: Ctrl + Shift + Alt + M)

  3. 화면이 글자만 있는 큰 상자 하나로 바뀝니다.
     상자 안을 클릭하고 Ctrl+A → Delete 로 기존 내용을 전부 지웁니다.

  4. "latex-gloss-60-body-blocks.txt" 를 메모장으로 열어
     Ctrl+A → Ctrl+C 하고, 상자에 Ctrl+V 로 붙여넣습니다.

  5. 다시 ⋮ → [편집기] → [시각적 편집기].
     문단 · 소제목 · 표가 각각 따로 들어가 있으면 성공입니다.

  6. [저장] 또는 [공개].


  ⚠️ 지금 화면에 "사용자 정의 HTML" 블록이 하나 들어가 있다면 잘못된 것입니다.

SeidenLatex 슬라이드를 받고 나서 원인이 보였습니다.
두 슬라이드를 나란히 놓으면 이렇습니다.

  Latex Gloss 60  제품명 Gloss(=광택)   머리말 "고광택"  →  광택도 "G2b 실크광(반광)"
  SeidenLatex     제품명 Seiden(=실크)  머리말 "실크광"  →  광택도 "유광"

둘 다 자기 제품명·머리말과 반대로 적혀 있고, **서로 바꾸면 둘 다 맞습니다.**

물증이 하나 더 있습니다.
SeidenLatex 슬라이드의 [색 상] 항목 두 번째 줄이

  "**Latex Gloss 60**은 ColorExpress 자동 조색 시스템을 통해…"

로 시작합니다. SeidenLatex 슬라이드인데 이 제품 이름이 들어가 있습니다.
두 슬라이드를 복사해서 만들다가 값이 섞인 것으로 보입니다.

  → 독일 TDS 원본에서 두 제품의 Glanzgrad 를 확인해 주세요.
  → 뒤바뀐 게 맞으면 두 파일에서 "광택도" 줄만 서로 바꾸면 됩니다.
    (제가 두 파일 모두에 교체용 문구를 적어 두었습니다)
  → 확인 전까지는 이 두 제품만 임시글로 두시는 걸 권합니다.
    나머지 7종은 먼저 공개하셔도 됩니다.
