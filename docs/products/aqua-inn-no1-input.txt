  1. 편집 화면 **오른쪽 맨 위, [저장] 버튼 바로 옆의 ⋮** 를 누릅니다.
     ★ 본문 안쪽에 뜨는 작은 ⋮ 가 아닙니다. 화면 제일 위쪽 ⋮ 입니다.

  2. 메뉴에서  [편집기] → [코드 편집기]  를 고릅니다.
     (단축키: Ctrl + Shift + Alt + M)

  3. 화면이 글자만 있는 큰 상자 하나로 바뀝니다.
     상자 안을 클릭하고 Ctrl+A → Delete 로 기존 내용을 전부 지웁니다.

  4. "aqua-inn-no1-body-blocks.txt" 를 메모장으로 열어
     Ctrl+A → Ctrl+C 하고, 상자에 Ctrl+V 로 붙여넣습니다.

  5. 다시 ⋮ → [편집기] → [시각적 편집기].
     문단 · 소제목 · 표가 각각 따로 들어가 있으면 성공입니다.

  6. [저장] 또는 [공개].

    그 블록을 클릭 → 블록 위 ⋮ → [삭제] 로 지우고 1번부터 다시 하세요.
