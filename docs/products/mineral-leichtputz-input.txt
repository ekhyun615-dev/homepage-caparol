⑤ 기술 데이터  (필드명: specs)
────────────────────────────────────────────
규격 : DIN EN 998-1 에 따른 경량 플라스터 모르타르 (LW, Type II)
밀도 : 약 1.3 g/cm³ 이하
열전도율 : λ10 dry,mat ≤ 0.45 W/(m·K) (P=50%) / ≤ 0.49 W/(m·K) (P=90%)
수증기 투과성 : µ ≤ 20 (DIN EN 1015-19 기준)
압축강도 : CS II 등급, 1.5~5.0 N/mm² (DIN EN 1015-11 기준)
부착인장강도 : fHZ ≥ 0.08 N/mm² (파단 형태 A·B·C, DIN EN 1015-12 기준)
내화등급 : A2-s1, d0 등급 (불연재) (DIN EN 13501-1 기준)
모세관 물 흡수 : WC2 등급, C ≤ 0.20 kg/(m²·min^½) (DIN EN 998-1 기준)
결합재 기반 : DIN EN 197-1·459-1 에 따른 미네랄계 결합재 + 실리케이트 첨가제
색상 : 내추럴 화이트 및 공장 착색 제품
포장 규격 : 25 kg / 포
