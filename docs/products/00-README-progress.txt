 파일 이름 안내
════════════════════════════════════════════════════════════

 파일 이름을 전부 영문으로 바꿨습니다.
 한글 이름이 윈도우에서 압축을 풀 때 깨져서 일부 파일이 사라졌습니다.

   ○○-input.txt          ← 워드프레스 각 칸에 붙여넣을 내용 (①~⑨)
   ○○-body-blocks.txt    ← 본문. 이걸 [코드 편집기] 에 붙여넣습니다  ★
   ○○-body.html          ← 같은 본문의 참고용 원본. 안 쓰셔도 됩니다
   00-README-progress.txt ← 지금 보고 계신 이 파일

 파일 안의 내용은 그대로 한글입니다. 이름만 영문입니다.

 붙여넣는 순서 (한 제품당 5분 정도)
════════════════════════════════════════════════════════════

  1. 관리자 → 제품 → 해당 제품 클릭
  2. "○○-input.txt" 를 열고 ①~⑤ 를 순서대로 붙여넣기
  3. 본문 — 화면 **맨 위 오른쪽 [저장] 옆의 ⋮** → [편집기] → [코드 편집기]
     (Ctrl+Shift+Alt+M) → 상자 안 Ctrl+A, Delete
     → "○○-body-blocks.txt" 전체를 Ctrl+A, Ctrl+C 해서 Ctrl+V
  4. 다시 ⋮ → [편집기] → [시각적 편집기]
  5. 오른쪽 [대표 이미지] 에 제품 사진 등록
  6. [공개]

  ※ 슬러그는 절대 건드리지 마세요. 주소가 바뀝니다.



════════════════════════════════════════════════════════════
 본문 붙여넣기가 잘 안 될 때
════════════════════════════════════════════════════════════

 ⋮ 버튼이 두 군데 있습니다. 헷갈리기 쉽습니다.

   ✅ 맞는 것 — 화면 **제일 위 오른쪽**, [저장] 버튼 바로 옆의 ⋮
                → [편집기] → [코드 편집기]
                → 글 전체가 글자만 있는 큰 상자로 바뀝니다

   ❌ 틀린 것 — 본문 안쪽 블록 위에 뜨는 작은 ⋮ 또는 [코드 편집]
                → 그 블록 하나만 코드로 보여줍니다
                → 여기에 붙여넣으면 "사용자 정의 HTML" 블록 하나로
                  뭉쳐지거나 태그가 다 벗겨진 글 한 덩어리가 됩니다

 이미 잘못 들어갔다면
   그 블록을 클릭 → 블록 위 ⋮ → [삭제] 로 지우고 처음부터 다시 하세요.
   저장하지 않았다면 Ctrl+Z 를 여러 번 눌러도 됩니다.

 왜 -body-blocks.txt 를 쓰나요
   워드프레스는 블록마다 <!-- wp:paragraph --> 같은 표시를 붙여 저장합니다.
   그 표시가 없는 순수 HTML 을 넣으면 문단·소제목·표를 구분하지 못합니다.
   -body-blocks.txt 에는 그 표시를 미리 붙여 두었습니다.
