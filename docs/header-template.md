# 헤더 만들기

지금 사이트에는 **메뉴가 하나도 없습니다.** 제품 페이지에 들어가면 다른 데로 갈 방법이 없습니다.
헤더가 생기는 순간 비로소 "사이트"가 됩니다.

---

## 먼저 — 메가메뉴는 나중에 합니다

`ia.md` §2에 4열 메가메뉴를 설계해뒀지만, **1차에서는 일반 드롭다운으로 갑니다.**

| | 일반 드롭다운 | 메가메뉴 |
|---|---|---|
| 작업 시간 | 30분 | 반나절 이상 |
| 필요한 것 | 메뉴 항목만 | 제품 아이콘·이미지·프로모 콘텐츠 |
| 지금 가능한가 | ✅ | ❌ 넣을 콘텐츠가 아직 없음 |

메가메뉴 우측 프로모 자리에 넣을 **준불연 성적서**도, 제품 아이콘도 아직 없습니다.
빈 메가메뉴는 일반 드롭다운보다 못합니다.

**순서**: 지금 → 일반 드롭다운으로 사이트를 돌아다닐 수 있게 만든다.
콘텐츠가 채워지면 → 메가메뉴로 교체한다. 헤더 템플릿 안에서 위젯만 바꾸면 됩니다.

---

## ⚠️ 시작 전 반드시 확인 — Atomic 편집기를 끄세요

**Elementor → 설정 → `Atomic 편집기` 탭 → `비활성화`**

Elementor의 새 실험 편집기입니다. 켜져 있으면 이런 일이 생깁니다.

- 편집기에서는 디자인이 멀쩡하게 보임
- **실제 사이트에는 스타일이 하나도 안 나감** — 정렬은 물론 색상까지 전부 무시됨
- 원인을 찾기가 매우 어려움 (캐시·조건·저장 문제로 오인하기 쉬움)

### 구분하는 법

컨테이너를 선택했을 때 왼쪽 패널의 **탭 이름**을 보세요.

| 탭 구성 | 정체 |
|---|---|
| `레이아웃` / `스타일` / `고급` | ✅ 검증된 기존 컨테이너 |
| `일반` / `스타일` / `상호작용` (+ ⊗ 원자 아이콘) | ❌ Atomic. 즉시 중단하고 위 설정을 끄세요 |

위젯 목록의 **`Atomic 요소`** 그룹(Div 블록·플렉스박스·그리드)도 같은 이유로 쓰지 않습니다.

> 함께 확인: **설정 → `성능` 탭 → CSS 인쇄 방법**. 스타일이 안 나가는 증상이 계속되면
> `내부 임베딩`으로 바꾸면 CSS 파일 생성 실패 문제를 우회할 수 있습니다.

## 1단계 · 빈 페이지 3개 만들기 (10분)

메뉴에 넣을 페이지가 아직 없습니다. **제목만 있는 빈 페이지**를 먼저 만들어두세요.
내용은 나중에 채웁니다.

**페이지 → 새로 추가** 를 3번 반복합니다.

| 제목 | 슬러그 | 나중에 채울 내용 |
|---|---|---|
| 브랜드 | `about` | DAW/Caparol 소개, 제조공장, 한국 공식 수입원 |
| 문의하기 | `contact` | 빠른 연락, 문의 폼, 오시는 길 |

> ⚠️ **슬러그를 영문으로** 지정하세요. 한글 제목이라 자동값이 한글이 됩니다.
> 오른쪽 사이드바 `슬러그` 항목에서 위 표의 값으로 바꾸고 **공개**.

빈 페이지라도 공개해야 메뉴에 넣을 수 있습니다.

---

## 2단계 · 메뉴 만들기 (10분)

**모양 → 메뉴**

1. 메뉴 이름: `주메뉴` → **메뉴 생성**
2. 왼쪽 상자들에서 항목을 골라 **메뉴에 추가**

### 최상위 6개

| 메뉴 이름 | 무엇을 추가하나 |
|---|---|
| 브랜드 | 페이지 → `브랜드` |
| 제품 | **사용자 정의 링크** → URL `/products/` · 링크 문구 `제품` |
| 컬러 | **사용자 정의 링크** → URL `/colors/` · 링크 문구 `컬러` |
| 시공사례 | **사용자 정의 링크** → URL `/references/` · 링크 문구 `시공사례` |
| 기술자료 | **사용자 정의 링크** → URL `/downloads/` · 링크 문구 `기술자료` |

> 제품·컬러·시공사례·기술자료는 **목록(아카이브) 주소**라서 페이지 목록에 안 나옵니다.
> `사용자 정의 링크` 상자에 주소를 직접 넣으세요.

### 하위 항목

`제품` 아래에 제품 카테고리 7개를 넣습니다.

1. 왼쪽 **제품 카테고리** 상자를 펼쳐서 7개 전체 선택 → 메뉴에 추가
2. 목록 맨 아래에 추가된 것들을 **마우스로 오른쪽으로 살짝 끌면** 하위 항목이 됩니다
   (들여쓰기된 것처럼 보이면 성공)

`시공사례` 아래에는 지역 분류에서 `국내` / `해외` 를 같은 방식으로.

3. **메뉴 저장**

> 이 단계에서 만든 메뉴는 헤더뿐 아니라 **푸터·모바일에서도 재사용**됩니다.
> 나중에 메뉴를 고치면 모든 곳에 한 번에 반영됩니다.

## 3단계 · Elementor 헤더 템플릿 (20분)

**Elementor → Theme Builder → 헤더 → 새로 추가**

- 템플릿 이름: `사이트 헤더`
- 라이브러리 팝업은 **닫기**

### 레이아웃 — 가로 3칸 컨테이너

```
┌──────────┬────────────────────────────┬───────────────────┐
│  로고     │  브랜드 제품▾ 컬러 시공사례▾   │ ☎ 전화  [문의하기] │
│          │  기술자료                   │                   │
└──────────┴────────────────────────────┴───────────────────┘
```

1. **+** → 컨테이너 추가 → 방향 **가로**
2. 컨테이너 선택 → `내용` 탭에서
   - 항목 정렬: **가운데**
   - 콘텐츠 폭: `1200px` (사이트 다른 부분과 맞춤)

### 넣을 위젯

| 위치 | 위젯 | 설정 |
|---|---|---|
| 왼쪽 | **사이트 로고** | 커스터마이저에 등록한 로고를 자동으로 씁니다 |
| 가운데 | **내비게이션 메뉴** | 메뉴에서 `주메뉴` 선택 |
| 오른쪽 | **버튼** | 텍스트 `문의하기` / 링크 `/contact/` |

> 로고가 아직 없으면 **제목** 위젯에 `CAPAROL KOREA` 를 넣어두세요
> (`brand/README.md` — 가로형 로고가 오면 교체).

### 버튼 색

- 배경: `#96c11c`
- 텍스트: **`#1a1a1a`** ← 흰 글씨는 대비 부족

## 4단계 · 표시 조건

**게시** → **Add condition** → **`Entire Site`**(전체 사이트) → **Save & Close**

> 헤더는 제품 템플릿과 달리 **전체 사이트**가 맞습니다.

---

## 5단계 · Astra 기본 헤더 끄기

Elementor 헤더를 만들면 대개 Astra 기본 헤더가 자동으로 대체됩니다.
그래도 **로고나 사이트 이름이 두 번 나오면** 아래에서 끄세요.

**모양 → 사용자 정의하기 → 헤더 빌더** 에서 요소를 비우거나,
**모양 → 사용자 정의하기 → 사이트 아이덴티티** 에서 `사이트 제목 표시` 해제

---

## 6단계 · 모바일 확인 ★

편집기 상단의 **휴대폰 아이콘**을 눌러 모바일 화면으로 전환합니다.

- [ ] 메뉴가 **햄버거 버튼(≡)** 으로 바뀌는가
- [ ] 눌렀을 때 메뉴가 펼쳐지는가
- [ ] 하위 항목(제품 카테고리 7개)이 접혔다 펴지는가
- [ ] 로고가 너무 크지 않은가 (높이 32~36px)
- [ ] `문의하기` 버튼이 잘리지 않는가

> **시공사·건축주는 현장에서 폰으로 봅니다.** 데스크톱보다 모바일이 중요합니다.

---

## 7단계 · 확인

실제 사이트를 열어봅니다. 상단바 **캐시 삭제** 먼저.

- [ ] 모든 페이지 상단에 헤더가 나오는가
- [ ] `제품` 에 마우스를 올리면 카테고리 7개가 펼쳐지는가
- [ ] 각 메뉴를 클릭하면 해당 페이지로 가는가
- [ ] 제품 상세 → 헤더의 `제품` 클릭 → 목록으로 돌아오는가

여기까지 되면 **사이트를 돌아다닐 수 있게 됩니다.**
