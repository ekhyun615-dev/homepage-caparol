# 운영 매뉴얼

오픈 이후 사이트를 살아있게 유지하는 규칙입니다. 담당자가 바뀌어도 이 문서만 보면 되도록 씁니다.

---

## 1. 백업 — 가장 중요

워드프레스 사고의 대부분은 백업이 없어서 복구를 못 하는 것입니다.

| 항목 | 설정 |
|---|---|
| 도구 | UpdraftPlus |
| 파일 백업 | 주 1회 |
| DB 백업 | **매일** (콘텐츠가 여기 들어있습니다) |
| 저장 위치 | **Google Drive 또는 Dropbox** (서버에만 두면 서버 사고 시 같이 날아갑니다) |
| 보관 개수 | 최근 4개 |

- [ ] 분기 1회 **복구 테스트** — 백업만 있고 복구가 안 되는 경우가 실제로 많습니다

## 2. 업데이트 규칙

| 대상 | 주기 | 방법 |
|---|---|---|
| 워드프레스 마이너 (6.5.1 → 6.5.2) | 자동 | 보안 패치. 자동으로 두세요 |
| 워드프레스 메이저 (6.5 → 6.6) | 출시 후 2~4주 뒤 | **백업 먼저** |
| 플러그인 | 월 1회 | **백업 먼저**, 한 번에 하나씩 |
| PHP 버전 | 연 1회 | 호스팅 관리에서. 사전 호환성 확인 |

> **철칙: 업데이트 전에 백업.** 금요일 오후에는 업데이트하지 마세요.

## 3. 정기 점검 (월 1회, 15분)

- [ ] 사이트 정상 접속 (PC + 모바일)
- [ ] 문의 폼 테스트 발송 → 수신 확인 ← **가장 자주 조용히 고장나는 부분**
- [ ] Wordfence 스캔 결과 확인
- [ ] 백업이 실제로 쌓이고 있는지 확인
- [ ] SSL 인증서 만료일 확인
- [ ] 구글 서치콘솔 오류 확인
- [ ] 스팸 댓글·가입자 정리

## 4. 연 1회

- [ ] 도메인 `caparol.kr` 갱신 ⚠️ **만료되면 사이트가 통째로 사라집니다**
- [ ] 호스팅 갱신
- [ ] 시험성적서 유효기간 확인 및 최신본 교체
- [ ] 오래된 시공사례 정리, 신규 추가
- [ ] 안 쓰는 플러그인 정리

## 5. 직원 콘텐츠 작업 규칙

- 계정 권한은 **편집자(Editor)** — 관리자 권한을 주지 마세요
- 사진 업로드 전 **가로 2000px 이하**로 줄이기
- 사진 파일명은 **영문**으로 (`caparol-yangpyeong-01.jpg`) — 한글 파일명은 서버에서 깨질 수 있습니다
- 이미지 **대체 텍스트(alt)** 입력 — 검색 노출에 직결
- 플러그인 설치·업데이트는 직원이 하지 않기

## 6. 사고 대응

| 증상 | 조치 |
|---|---|
| 사이트가 안 열림 | 호스팅 상태 확인 → 최근 업데이트한 플러그인 비활성화 → 백업 복구 |
| 화면이 하얗게(백지) | FTP로 `wp-content/plugins/` 폴더명을 임시로 바꿔 전체 비활성화 → 하나씩 복구 |
| 이상한 광고·리다이렉트 | **해킹**. 즉시 사이트 내리고 Wordfence 스캔 → 깨끗한 백업으로 복구 → 전 비밀번호 변경 |
| 검색에서 사라짐 | 설정 → 읽기 → "검색 엔진 노출 방지" 체크 여부 확인 (1순위 원인) |
| 문의 메일이 안 옴 | 스팸함 확인 → SMTP 플러그인으로 발송 방식 변경 |
