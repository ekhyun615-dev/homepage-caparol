## 0. 사업 형태 — 모든 판단의 전제

**Caparol Korea 명의로 직접 수입·판매합니다.**
단순 재판매상이 아니라 **한국 공식 수입원**이라는 뜻이고, 사이트가 이 위치를 드러내야 합니다.

| 함의 | 사이트에 미치는 영향 |
|---|---|
| 공식 수입원 = 브랜드의 한국 얼굴 | 개인 쇼핑몰이 아니라 **브랜드 사이트**의 격이 필요. 디자인·사진 품질이 곧 브랜드 신뢰 |
| 유통망(대리점·취급점)이 필요 | **대리점 안내/모집 페이지**와 전용 문의 경로 필요 |
| 기술 문의의 최종 책임자 | 시공 하자·기술 문의가 여기로 옴 → 기술지원 창구를 명확히 |
| 성적서·인증서의 보유 주체 | 국내 시험성적서를 직접 발급받아 게시. **경쟁 우위의 핵심** |
| B2B 비중이 큼 | 가격 노출보다 **견적 문의 유도**. 온라인 판매는 하지 않음 |

> 사이트 하단과 About에 **본사와의 관계**를 명시하세요.
> "독일 Caparol(DAW SE)의 한국 공식 수입원" — 이 한 줄이 신뢰의 절반입니다.
> 표기 문구는 본사 승인을 받는 것이 안전합니다.

## 1. 이 사이트의 목적

| 순위 | 목표 |
|---|---|
| 1 | **문의 유도** — 설계사·시공사·건축주가 견적/샘플을 요청하게 만든다 |
| 2 | **기술 신뢰 확보** — 시험성적서·TDS·시공지침으로 "쓸 수 있는 제품"임을 증명한다 |
| 3 | **유통망 확대** — 대리점·취급점 문의를 받는다 |
| 4 | **브랜드 전달** — 독일 130년, DAW 그룹, 공식 수입원 지위 |

### 방문자 4분류와 각자가 원하는 것

| 방문자 | 원하는 것 | 사이트에서 도달해야 할 곳 |
|---|---|---|
| **설계사·감리** | 스펙, 시험성적서, 준불연 인증, TDS | 제품 상세 → 기술자료 |
| **시공사** | 시공지침, 소요량, 부자재, 단가 문의 | 제품 상세 → 시공지침 → 문의 |
| **건축주** | 색상, 실제 사례 사진, "우리 집에 어떻게 보일까" | 컬러 → 시공사례 → 문의 |
| **대리점 희망 업체** | 취급 조건, 공급 구조, 연락처 | 대리점 안내 → 대리점 문의 |

> ⚠️ CREATON(기와)과 가장 다른 점: **컬러**와 **시험성적서**가 결정적입니다.
> 도료는 색이 곧 제품이고, 외단열은 건축법상 화재 규정 때문에 인증서가 채택 여부를 가릅니다.

### 상단 메뉴 (GNB) — 6개로 제한

```
브랜드   제품 ▾   컬러   시공사례 ▾   기술자료   대리점       [문의하기]  ☎ 1588-XXXX
```

기존 기획안은 **최상위 메뉴가 9개**였습니다(DAW/Caparol · 프라이머 · 페인트 · 플라스터/퍼티 ·
유리직물벽지 · 장식인테리어 · 외단열시스템 · Meldorfer · 시공사례).
이건 데스크톱에서도 줄이 넘치고 모바일에서는 스크롤이 깁니다.

**제품 7종을 `제품 ▾` 하나로 묶는 것을 권합니다.** 내용은 하나도 안 버립니다.

```
제품 ▾
 ├ 프라이머
 ├ 페인트
 ├ 플라스터 / 퍼티
 ├ 유리직물벽지 (Capaver)
 ├ 장식 인테리어 (Capadecor)
 ├ 외단열시스템 (EIFS)
 └ Meldorfer 벽돌마감
```

- 최상위 6개 = 한 줄에 들어가고, 모바일에서도 한눈에 잡힙니다
- 방문자는 "프라이머"를 찾는 게 아니라 **"내 현장에 뭘 쓰지"** 를 찾습니다. 제품군은 그 다음 층입니다
- 공지사항·게시판은 GNB가 아니라 **푸터 + 홈 하단**에 배치
- `대리점`은 유통망 확대가 목표 3순위이므로 최상위에 유지

### 메가메뉴 설계

제품 7종에 하위 항목이 총 30개 가까이 됩니다. 일반 드롭다운으로는 세로로 길게 늘어져
읽히지 않으므로 **메가메뉴**로 펼칩니다.

#### `제품` 메가메뉴 — 4열 그리드 + 우측 프로모

```
┌───────────────┬───────────────┬───────────────┬──────────────────────┐
│ 프라이머       │ 플라스터/퍼티  │ 장식 인테리어  │                      │
│ · 프라이머     │ · 외장 플라스터│ · Capadecor   │   [ 제품 이미지 ]     │
│ · 외벽 발수제  │ · 내장 플라스터│ · 퍼티 마감    │                      │
│               │ · 퍼티         │               │   준불연 시험성적서    │
├───────────────┼───────────────┼───────────────┤   다운로드  →         │
│ 페인트         │ 유리직물벽지   │ 외단열시스템   │                      │
│ · 인테리어     │ · 종류 · 규격  │ · 시스템 종류  │   ─────────────      │
│ · E.L.F.Plus  │ · 특성 · 용도  │ · EIFS 단열재  │   컬러 시스템 보기 →   │
│ · 외장 페인트  │ · Capaver Sys.│ · 보강메쉬     │                      │
│               │ · 보완제품     │ · 플라스터     │                      │
├───────────────┼───────────────┼───────────────┤                      │
│ Meldorfer 벽돌마감                             │                      │
│ · 종류/규격  · Original Meldorfer               │                      │
│ · 용도·특성  · Nature Element  · 보완제품        │                      │
└────────────────────────────────────────────────┴──────────────────────┘
```

- 카테고리명은 **클릭 가능** — 카테고리 목록 페이지로 이동
- 각 카테고리명 왼쪽에 작은 아이콘을 두면 훑어보기가 쉬워집니다
- 우측 프로모 영역은 **가장 원하는 행동 하나**만 둡니다.
  이 사이트에서는 **준불연 시험성적서 다운로드** — 설계사의 채택을 좌우하는 자료입니다

#### `시공사례` 메가메뉴 — 작게

```
┌─────────────┬────────────────────────────────────────┐
│ 국내사례     │  [썸네일]   [썸네일]   [썸네일]          │
│ 해외사례     │  최근 등록된 시공사례 3건                 │
│             │                                        │
│ 건물 용도 ▾  │                                        │
│ · 단독주택   │                                        │
│ · 상업시설   │                                        │
│ · 공공건축   │                                        │
│ · 산업시설   │                                        │
└─────────────┴────────────────────────────────────────┘
```

#### 규칙

| 항목 | 값 |
|---|---|
| 펼침 방식 | **마우스 올리면(hover)** 펼침. 클릭 방식은 데스크톱에서 답답합니다 |
| 폭 | 화면 전체 폭(full width), 내용은 `--caparol-max`(1200px) 안에 정렬 |
| 모바일 | 메가메뉴 **금지** → 아코디언(펼침 목록)으로 자동 전환 |
| 열림 지연 | 100~150ms — 메뉴를 지나가기만 해도 열리면 성가십니다 |
| 강조색 | 카테고리명 hover 시 `--caparol-green-dark`, 좌측 3px `--caparol-green` |

> **모바일이 진짜 중요합니다.** 시공사·건축주는 현장에서 폰으로 봅니다.
> 메가메뉴를 데스크톱에서 아무리 잘 만들어도 모바일에서 아코디언이 안 되면 소용없습니다.
> 만들 때 **모바일 화면을 먼저** 확인하세요.
- 우측 상단 **문의하기 버튼은 항상 노출** (색상 대비 강하게)
- 모바일: 하단 고정 바 = `☎ 전화` / `💬 카카오톡` / `📝 상담신청` (creaton.kr의 FloatingCTA와 동일 패턴)

### 브랜드 소개 `/about` 에 들어갈 내용

기존 메뉴의 `DAW/Caparol`(회사 소개, 제조공장)은 별도 최상위 메뉴가 아니라
`/about` 안으로 넣습니다.

- DAW SE 그룹과 Caparol의 관계
- 창립 1895, 유럽 시장 지위
- **제조공장** — 독일 생산시설 사진·설명 (기존 메뉴에 있던 항목)
- **한국 공식 수입원**으로서의 Caparol Korea

> Meldorfer 메뉴에도 "제조공장" 항목이 따로 있었습니다.
> 제품군별 생산시설 이야기는 해당 제품 페이지 안에 두고, 회사 차원의 이야기만 `/about`에 두세요.

### ⚠️ 표기 오류 하나

기존 메뉴의 **`Original Neldorfer`** 는 오타로 보입니다.
같은 메뉴의 하위 항목에는 `Original Meldorfer`로 적혀 있고, 정식 브랜드명은 **Meldorfer** 입니다.
사이트 전체에서 `Meldorfer`로 통일하세요.

### 시공사례 구분

기존 메뉴대로 **국내사례 / 해외사례**로 나눕니다.
`reference_region` 분류를 계층형으로 만들어 두었으므로 이렇게 씁니다.

```
국내
 ├ 서울 · 경기
 ├ 충청
 └ …
해외
 ├ 독일
 └ …
```

> 해외사례는 본사 자료를 쓰게 되는데, **이미지 사용 권한을 먼저 확인**하세요.
> 그리고 해외사례만 많고 국내사례가 적으면 "한국에서는 실적이 없나" 로 읽힙니다.
> 국내사례를 먼저 채우고 해외를 보조로 두세요.

## 4. 페이지별 구성

### 홈 `/`

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 히어로 | 실제 시공 전경 사진 슬라이드 3~5장 + 한 줄 카피 + `제품 보기` / `문의하기` |
| 2 | 브랜드 신뢰 | 숫자 4개 — 창립 1895 · 유럽 OO개국 · 국내 시공 OO건 · 준불연 인증 |
| 2-b | 공식 수입원 표기 | "독일 Caparol 한국 공식 수입원" 한 줄 + 본사 로고 |
| 3 | 제품 카테고리 | 카드 7개 (§3 확정 라인업) |
| 4 | 컬러 시스템 | 색상 팔레트 미리보기 + `전체 색상 보기` |
| 5 | 시공사례 | 최신 6건 그리드 |
| 6 | 기술자료 | 자주 찾는 PDF 4개 바로가기 (준불연 성적서를 맨 앞에) |
| 7 | 공지사항 | 최신 3건 |
| 8 | 문의 CTA | 전화 · 카카오 · 상담신청 폼 |

### 제품 상세 `/products/[제품명]`

```
┌──────────────────┬───────────────────────────┐
│  제품 이미지       │  제품명 (한글 / 원어)        │
│  (갤러리)         │  한 줄 요약                 │
│                  │  용도 · 적용 부위            │
│                  │  [ 견적 문의 ] [ 샘플 신청 ]  │
└──────────────────┴───────────────────────────┘
  ▸ 주요 특징 (3~5개, 아이콘 + 한 줄)
  ▸ 기술 데이터 표   ← 광택 / 희석 / 소요량 / 건조시간 / 용기규격 / 색상
  ▸ 색상            ← /colors 로 연결
  ▸ 관련 자료        ← TDS · 시공지침 · 시험성적서 PDF
  ▸ 이 제품 시공사례  ← 태그로 자동 연결
  ▸ 문의 CTA
```

> creaton.kr의 제품 `.md` front-matter(`specs`, `colors`, `gallery`)와 같은 구조입니다.
> 워드프레스에서는 **ACF 반복 필드**로 구현합니다 (§ wordpress-setup.md 참고).

### 컬러 시스템 `/colors` ★

도료 사이트에서 **가장 많이 보는 페이지**입니다. 여기에 제일 공을 들이세요.

- 색상 칩 그리드 (색상번호 + 색상명)
- 필터: 색계열 / 제품군 / 실내·실외
- 색상 클릭 → 색상번호, 적용 가능 제품, 해당 색 시공사례
- **주의 문구 필수**: "모니터 환경에 따라 실제 색상과 차이가 있습니다. 시공 전 실물 색상집으로 확인하시기 바랍니다."
- 실물 색상집 신청 버튼 → 문의 폼

### 시공 사례 `/references/[현장명]`

- 대표 사진 + 사진 갤러리 5~10장
- 현장 정보 표: 위치 / 건물 용도 / 준공 연도 / **사용 제품** / 시공 면적
- 사용 제품은 제품 페이지로 링크 (내부 링크 = SEO + 회유)
- 필터: 제품별 / 건물 용도별(주택·상가·공공) / 지역별

### 대리점 안내 `/partners`

직접 수입·판매 구조이므로 유통망 확대가 사이트의 실질 목표 중 하나입니다.

- 취급 조건 안내 (자격, 최소 물량, 지원 사항)
- 공급 구조 설명 — "본사 직수입 → 대리점 → 시공" 도식
- 본사가 제공하는 것: 기술교육, 시공지원, 카탈로그·샘플, 시험성적서
- **대리점 문의 폼** (일반 문의와 분리)
- 기존 취급점이 생기면 → 지역별 취급점 목록

> 초기에 취급점이 없으면 목록은 빼고 **"대리점 모집"** 성격으로만 운영하세요.
> 빈 목록은 사업이 작아 보이게 만듭니다.

## 5. 워드프레스 구현 매핑

| 사이트 요소 | 워드프레스 구현 |
|---|---|
| 제품 | 커스텀 포스트 타입 `product` + 택소노미 `product_cat` |
| 제품 스펙표 · 색상 · 갤러리 | **ACF (Advanced Custom Fields)** 반복 필드 |
| 시공사례 | 커스텀 포스트 타입 `reference` + 택소노미 `reference_cat` |
| 색상 | 커스텀 포스트 타입 `color` (색상번호, HEX, 계열) |
| 기술자료 | 커스텀 포스트 타입 `document` (파일 첨부 + 분류) |
| 공지사항 | 워드프레스 **기본 글(post)** — 새로 만들지 말 것 |
| 문의 게시판 / 자료실 | KBoard (한국형 게시판) |
| 문의 폼 | Contact Form 7 또는 WPForms |

> 제품을 "페이지"로 만들지 마세요. 100개가 되면 관리가 불가능해집니다.
> 반드시 **커스텀 포스트 타입 + 카테고리**로 만들어야 목록·필터·메뉴가 자동으로 됩니다.
