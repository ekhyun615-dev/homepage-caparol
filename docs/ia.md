# caparol.kr 사이트 구조 설계서 (IA)

> **이 문서를 확정한 뒤에 워드프레스를 만지세요.**
> 워드프레스 프로젝트가 망가지는 건 대부분 구조 없이 페이지부터 만들기 시작해서입니다.
> 나중에는 구조를 못 바꿉니다.

---

## 1. 이 사이트의 목적

| 순위 | 목표 |
|---|---|
| 1 | **문의 유도** — 설계사·시공사·건축주가 견적/샘플을 요청하게 만든다 |
| 2 | **기술 신뢰 확보** — 시험성적서·TDS·시공지침으로 "쓸 수 있는 제품"임을 증명한다 |
| 3 | **브랜드 전달** — 독일 130년, DAW 그룹, 유럽 시장 점유율 |

### 방문자 3분류와 각자가 원하는 것

| 방문자 | 원하는 것 | 사이트에서 도달해야 할 곳 |
|---|---|---|
| **설계사·감리** | 스펙, 시험성적서, 준불연 인증, TDS | 제품 상세 → 기술자료 |
| **시공사** | 시공지침, 소요량, 부자재, 단가 문의 | 제품 상세 → 시공지침 → 문의 |
| **건축주** | 색상, 실제 사례 사진, "우리 집에 어떻게 보일까" | 컬러 → 시공사례 → 문의 |

> ⚠️ CREATON(기와)과 가장 다른 점: **컬러**와 **시험성적서**가 결정적입니다.
> 도료는 색이 곧 제품이고, 외단열은 건축법상 화재 규정 때문에 인증서가 채택 여부를 가릅니다.

## 2. 메뉴 구조

```
/                          홈
/about                     브랜드 소개
/products                  제품
   /products/etics           └ 외단열시스템 (Capatect)
   /products/exterior        └ 외부 도료
   /products/interior        └ 내부 도료
   /products/render          └ 미장 · 스타코
   /products/decor           └ 장식 마감 (Capadecor)
   /products/[제품명]         └ 제품 상세
/colors                    컬러 시스템          ★ 도료 브랜드의 핵심
/references                시공 사례
   /references/[현장명]       └ 사례 상세
/downloads                 기술자료 (카탈로그 · TDS · 시공지침 · 시험성적서)
/notice                    공지사항              ← 게시판
/board                     문의 게시판 / 자료실   ← 게시판
/contact                   문의하기 · 오시는 길
/privacy                   개인정보처리방침
```

### 상단 메뉴 (GNB) — 5개로 제한

```
브랜드   제품 ▾   컬러   시공사례   기술자료          [문의하기]  ☎ 1588-XXXX
```

- 공지사항·게시판은 GNB가 아니라 **푸터 + 홈 하단**에 배치 (방문자 우선순위가 낮음)
- 우측 상단 **문의하기 버튼은 항상 노출** (색상 대비 강하게)
- 모바일: 하단 고정 바 = `☎ 전화` / `💬 카카오톡` / `📝 상담신청` (creaton.kr의 FloatingCTA와 동일 패턴)

## 4. 페이지별 구성

### 홈 `/`

| 순서 | 섹션 | 내용 |
|---|---|---|
| 1 | 히어로 | 실제 시공 전경 사진 슬라이드 3~5장 + 한 줄 카피 + `제품 보기` / `문의하기` |
| 2 | 브랜드 신뢰 | 숫자 4개 — 창립 1895 · 유럽 OO개국 · 국내 시공 OO건 · 준불연 인증 |
| 3 | 제품 카테고리 | 카드 5개 (외단열 / 외부도료 / 내부도료 / 스타코 / 장식마감) |
| 4 | 컬러 시스템 | 색상 팔레트 미리보기 + `전체 색상 보기` |
| 5 | 시공사례 | 최신 6건 그리드 |
| 6 | 기술자료 | 자주 찾는 PDF 4개 바로가기 (준불연 성적서를 맨 앞에) |
| 7 | 공지사항 | 최신 3건 |
| 8 | 문의 CTA | 전화 · 카카오 · 상담신청 폼 |

### 제품 상세 `/products/[제품명]`

```
┌──────────────────┬───────────────────────────┐
│  제품 이미지       │  제품명 (한글 / 원어)        │
│  (갤러리)         │  한 줄 요약                 │
│                  │  용도 · 적용 부위            │
│                  │  [ 견적 문의 ] [ 샘플 신청 ]  │
└──────────────────┴───────────────────────────┘
  ▸ 주요 특징 (3~5개, 아이콘 + 한 줄)
  ▸ 기술 데이터 표   ← 광택 / 희석 / 소요량 / 건조시간 / 용기규격 / 색상
  ▸ 색상            ← /colors 로 연결
  ▸ 관련 자료        ← TDS · 시공지침 · 시험성적서 PDF
  ▸ 이 제품 시공사례  ← 태그로 자동 연결
  ▸ 문의 CTA
```

> creaton.kr의 제품 `.md` front-matter(`specs`, `colors`, `gallery`)와 같은 구조입니다.
> 워드프레스에서는 **ACF 반복 필드**로 구현합니다 (§ wordpress-setup.md 참고).

### 컬러 시스템 `/colors` ★

도료 사이트에서 **가장 많이 보는 페이지**입니다. 여기에 제일 공을 들이세요.

- 색상 칩 그리드 (색상번호 + 색상명)
- 필터: 색계열 / 제품군 / 실내·실외
- 색상 클릭 → 색상번호, 적용 가능 제품, 해당 색 시공사례
- **주의 문구 필수**: "모니터 환경에 따라 실제 색상과 차이가 있습니다. 시공 전 실물 색상집으로 확인하시기 바랍니다."
- 실물 색상집 신청 버튼 → 문의 폼

### 시공 사례 `/references/[현장명]`

- 대표 사진 + 사진 갤러리 5~10장
- 현장 정보 표: 위치 / 건물 용도 / 준공 연도 / **사용 제품** / 시공 면적
- 사용 제품은 제품 페이지로 링크 (내부 링크 = SEO + 회유)
- 필터: 제품별 / 건물 용도별(주택·상가·공공) / 지역별

### 기술자료 `/downloads`

| 구분 | 내용 |
|---|---|
| 카탈로그 | 제품군별 종합 카탈로그 |
| 기술자료(TDS) | 제품별 기술 데이터 시트 |
| 시공지침 | 시공 순서·주의사항 |
| **시험성적서·인증서** | **준불연 성적서(KS F ISO 5660-1), 친환경 인증** ← 최상단 배치 |

> 준불연 성적서는 설계사가 채택 여부를 결정하는 자료입니다.
> [건축법 제52조 / 피난·방화구조 규칙](https://www.law.go.kr/lumLsLinkPop.do?lspttninfSeq=105201&chrClsCd=010202)에 따라
> 외벽 외측 단열재는 준불연 이상이어야 합니다. 이 서류가 사이트에서 3초 안에 나와야 합니다.

### 문의 `/contact`

- 빠른 연락: 전화 / 카카오채널 / 이메일 (아이콘 3개)
- 문의 폼: 이름 · 연락처 · 이메일 · **문의유형(견적/샘플/기술/기타)** · 현장위치 · 내용 · 개인정보 동의
- 오시는 길: 지도 + 주소 + 대중교통
- 사업자 정보 (상호 / 대표 / 사업자번호 / 주소 / 전화 / 팩스)

## 5. 워드프레스 구현 매핑

| 사이트 요소 | 워드프레스 구현 |
|---|---|
| 제품 | 커스텀 포스트 타입 `product` + 택소노미 `product_cat` |
| 제품 스펙표 · 색상 · 갤러리 | **ACF (Advanced Custom Fields)** 반복 필드 |
| 시공사례 | 커스텀 포스트 타입 `reference` + 택소노미 `reference_cat` |
| 색상 | 커스텀 포스트 타입 `color` (색상번호, HEX, 계열) |
| 기술자료 | 커스텀 포스트 타입 `document` (파일 첨부 + 분류) |
| 공지사항 | 워드프레스 **기본 글(post)** — 새로 만들지 말 것 |
| 문의 게시판 / 자료실 | KBoard (한국형 게시판) |
| 문의 폼 | Contact Form 7 또는 WPForms |

> 제품을 "페이지"로 만들지 마세요. 100개가 되면 관리가 불가능해집니다.
> 반드시 **커스텀 포스트 타입 + 카테고리**로 만들어야 목록·필터·메뉴가 자동으로 됩니다.

## 6. SEO 규칙

| 항목 | 규칙 |
|---|---|
| 제품 페이지 title | `제품명 \| 카테고리 \| 카파롤 코리아` |
| 시공사례 title | `현장명 (지역) 시공사례 \| 카파롤 코리아` |
| URL | 한글 슬러그 금지 → 영문 소문자·하이픈 (`/products/amphibolin`) |
| 이미지 | 파일명 영문 + alt 텍스트 필수 |
| 등록 | 네이버 서치어드바이저 + 구글 서치콘솔 (사이트맵 제출) |
| 노려야 할 검색어 | `외단열 마감재`, `준불연 외단열`, `독일 외벽 도료`, `스타코 시공`, `카파롤` |

## 7. 열어두는 결정 사항

- [ ] 제품 분류 확정 (§3 체크박스)
- [ ] 컬러 시스템에 몇 개 색상을 올릴 것인가 (전체 vs 대표 색상만)
- [ ] 자료실을 **로그인 회원 전용**으로 할 것인가 (설계사 자료 요청 리드 확보용)
- [ ] 문의 게시판을 공개로 둘 것인가 (비공개 문의 접수만 받을 것인가)
- [ ] 영문 페이지 필요 여부
