# ACF 필드 설정

제품·색상·시공사례·기술자료에 들어갈 입력 칸을 만듭니다.
**필드 이름(Field Name)은 코드가 참조하므로 정확히 그대로 입력하세요.** 라벨은 자유롭게 바꿔도 됩니다.

> 만든 필드는 `theme/caparol-child/acf-json/` 에 자동 저장됩니다.
> 그 폴더를 저장소에 올리면 서버로 옮길 때 파일 복사만으로 끝납니다.

만드는 곳: **ACF → 필드 그룹 → 새로 추가**

---

## 1. 필드 그룹 `제품 상세`

**위치 규칙**: `포스트 타입` = `product` (제품)

| 순서 | 라벨 | 필드 이름 | 타입 | 설정 |
|---|---|---|---|---|
| 1 | 한 줄 요약 | `summary` | 텍스트 | 검색결과·목록에 노출. 60자 이내 |
| 2 | 용도 · 적용 부위 | `usage` | 텍스트 영역 | |
| 3 | 주요 특징 | `features` | **반복 필드** | 최소 3 / 최대 5 |
| 3-1 | └ 특징 | `text` | 텍스트 | 반복 필드 안의 하위 필드 |
| 4 | 기술 데이터 | `specs` | **반복 필드** | ⚠️ 이름 정확히 |
| 4-1 | └ 항목명 | `label` | 텍스트 | 예: 소요량 |
| 4-2 | └ 값 | `value` | 텍스트 | 예: 0.15~0.20 ℓ/㎡ |
| 5 | 색상 | `product_colors` | 관계(Relationship) | 대상: `color` |
| 6 | 관련 자료 | `documents` | 관계(Relationship) | 대상: `document` |
| 7 | 제품 사진 | `gallery` | 갤러리 | |

> `specs` / `label` / `value` 세 이름은 `functions.php` 의 `caparol_specs_table()` 이
> 직접 참조합니다. 다르게 쓰면 규격표가 빈 채로 나옵니다.

### 기술 데이터에 넣을 항목 (제품군별)

무엇을 채워야 할지 막힐 때 참고하세요.

| 제품군 | 넣을 항목 |
|---|---|
| 페인트 · 프라이머 | 광택도, 희석률, 소요량, 건조시간(지촉/재도장), 시공온도, 용기 규격, 색상 |
| 플라스터 · 퍼티 | 입도, 소요량, 두께, 가사시간, 양생시간, 포장 단위 |
| 유리직물벽지 | 폭, 길이, 중량, 방화등급, 재도장 가능 횟수 |
| 외단열시스템 | 단열재 종류·두께, 열전도율, **화재 등급(준불연)**, 부착 방식 |
| Meldorfer | 규격(가로×세로×두께), 중량, 시공 가능 바탕, 흡수율 |

## 2. 필드 그룹 `색상`

**위치 규칙**: `포스트 타입` = `color`

| 라벨 | 필드 이름 | 타입 | 비고 |
|---|---|---|---|
| 색상 번호 | `color_code` | 텍스트 | 예: `Caparol 3D 15` |
| 색상 값 | `color_hex` | **컬러 피커** | 화면에 칩으로 표시됨 |
| 비고 | `color_note` | 텍스트 | 예: 외부 전용 |

> 색상 글의 **제목**에는 색상명을 씁니다. 색상번호는 `color_code` 에 따로 넣으세요.
> 나중에 번호로 검색·정렬할 수 있습니다.

## 3. 필드 그룹 `시공사례 정보`

**위치 규칙**: `포스트 타입` = `reference`

| 라벨 | 필드 이름 | 타입 | 비고 |
|---|---|---|---|
| 위치 | `location` | 텍스트 | 시/군까지. 예: 경기 양평군 |
| 준공 연도 | `year` | 숫자 | |
| 시공 면적 | `area` | 텍스트 | 예: 320㎡ |
| 사용 제품 | `used_products` | 관계 | 대상: `product` ★ |
| 사진 | `gallery` | 갤러리 | 5~10장 |

> `used_products` 가 중요합니다. 사례 → 제품으로 링크가 생기고,
> 제품 페이지에서는 "이 제품 시공사례"가 자동으로 모입니다.
> 내부 링크가 촘촘해지면 검색 노출에도 유리합니다.

---

## 4. 필드 그룹 `기술자료`

**위치 규칙**: `포스트 타입` = `document`

| 라벨 | 필드 이름 | 타입 | 비고 |
|---|---|---|---|
| 파일 | `file` | 파일 | PDF |
| 설명 | `doc_note` | 텍스트 | |
| 유효기간 | `valid_until` | 날짜 선택 | **시험성적서용** |

> 시험성적서는 유효기간이 있습니다. 만료된 성적서가 사이트에 걸려 있으면
> 설계사에게 신뢰를 잃습니다. 날짜를 넣어두면 **기술자료 목록 화면에
> 만료 여부가 자동으로 표시**됩니다 (`functions.php` 에 구현되어 있습니다).

---

## 만든 뒤 확인

- [ ] **제품 → 새로 추가** 에 위 입력 칸들이 보인다
- [ ] 제품 1개를 시험 삼아 입력해본다 (기술 데이터 3줄 정도)
- [ ] `theme/caparol-child/acf-json/` 안에 `.json` 파일이 생겼다
      ← 안 생겼으면 폴더 쓰기 권한 문제. 폴더가 있는지부터 확인

여기까지 되면 **Elementor 테마 빌더로 제품 상세 템플릿**을 만들 차례입니다.
