# ACF 필드 설정 (무료판 기준)

제품·색상·시공사례·기술자료에 들어갈 입력 칸을 만듭니다.
**필드 명은 코드가 참조하므로 표에 적힌 그대로 입력하세요.** 레이블은 자유롭게 바꿔도 됩니다.

만드는 곳: **ACF → 필드 그룹 → 새로 추가**

## 화면 용어 대조표

ACF 한글판은 영어 문서와 용어가 다릅니다. 이 문서는 **화면에 나오는 말**을 씁니다.

| 영어 원문 | 화면에 나오는 말 |
|---|---|
| Field Label | **필드 레이블** — 편집 화면에 보일 이름 (한글 OK) |
| Field Name | **필드 명** — 코드가 참조하는 이름 (**반드시 영문**) |
| Field Type | **필드 유형** |
| Post Type | **게시물 유형** |
| Location Rules | **위치 규칙** |
| Relationship | **관계** |

> ⚠️ **필드 레이블에 한글을 입력하면 필드 명이 자동으로 이상하게 생성됩니다.**
> 필드를 추가할 때마다 **필드 명 칸을 지우고 영문으로 직접 입력**하세요.
> 이걸 놓치면 화면에는 아무 문제가 없어 보이는데 앞화면에 값이 안 나옵니다.

> **이 문서는 ACF 무료판을 전제로 합니다.**
> 반복 필드·갤러리 필드는 PRO 전용이라, 그 자리를 **텍스트영역 + 코드 렌더링**으로 대체했습니다.
> 나중에 PRO로 올리면 반복 필드로 옮길 수 있습니다.

## 1. 필드 그룹 `제품 상세`

**위치 규칙**: `게시물 유형` **같음** `제품`

| 순서 | 필드 레이블 | 필드 명 | 필드 유형 | 비고 |
|---|---|---|---|---|
| 1 | 한 줄 요약 | `summary` | 텍스트 | 검색결과·목록에 노출. 60자 이내 |
| 2 | 용도 · 적용 부위 | `usage` | 텍스트 영역 | |
| 3 | 주요 특징 | `features` | **텍스트 영역** | 한 줄에 하나 |
| 4 | 기술 데이터 | `specs` | **텍스트 영역** | 한 줄에 `항목 : 값` |
| 5 | 색상 | `product_colors` | 관계 | 포스트 타입 필터: 색상 |
| 6 | 관련 자료 | `documents` | 관계 | 포스트 타입 필터: 기술자료 |

> 제품 사진은 별도 필드를 두지 않습니다.
> 대표 사진은 워드프레스 기본 **특성 이미지**를, 여러 장은 본문의 **갤러리 블록**을 쓰세요.

### 기술 데이터 입력 방법 ★

`specs` 텍스트영역에 **한 줄에 하나씩** 이렇게 씁니다.

```
광택도 : 무광
소요량 : 0.15~0.20 ℓ/㎡
희석률 : 물 5% 이내
건조시간 : 지촉 2시간 / 재도장 12시간
시공온도 : 5℃ 이상
용기규격 : 2.5ℓ / 12.5ℓ
```

화면에는 자동으로 표가 됩니다. 알아두면 좋은 것:

| 상황 | 결과 |
|---|---|
| 값에 콜론이 있음 (`혼합비 : 1:3`) | ✅ 정상. 첫 콜론에서만 나눕니다 |
| **엑셀에서 두 칸 복사해 붙여넣기** | ✅ 정상. 탭 구분을 인식합니다 |
| 전각 콜론(`：`)을 씀 | ✅ 정상 |
| 콜론을 빠뜨림 | ⚠️ 그 줄이 표에 **한 칸으로 넓게** 나옵니다 — 보이면 고치세요 |
| 빈 줄 | 무시됩니다 |

> 제품 자료를 스프레드시트로 정리하실 거라면, **항목·값 두 열을 복사해서 그대로 붙여넣으면 됩니다.**

### 주요 특징 입력 방법

`features` 텍스트영역에 한 줄에 하나씩. 줄 앞의 `-` `·` `•` 는 알아서 떼어냅니다.

```
독일 본사 생산 원료 사용
우수한 내후성 및 색상 유지력
곰팡이·조류 억제 기능
```

### 화면에 표시하기 (Elementor)

제품 상세 템플릿에서 **단축코드 위젯**을 놓고 아래를 입력합니다.

```
[caparol_features]     주요 특징 목록
[caparol_specs]        기술 데이터 표
```

나머지 필드(요약·용도·색상·관련자료)는 Elementor의 **동적 태그 → ACF 필드**로 직접 연결하면 됩니다.

### 기술 데이터에 넣을 항목 (제품군별)

| 제품군 | 넣을 항목 |
|---|---|
| 페인트 · 프라이머 | 광택도, 희석률, 소요량, 건조시간(지촉/재도장), 시공온도, 용기 규격 |
| 플라스터 · 퍼티 | 입도, 소요량, 두께, 가사시간, 양생시간, 포장 단위 |
| 유리직물벽지 | 폭, 길이, 중량, 방화등급, 재도장 가능 횟수 |
| 외단열시스템 | 단열재 종류·두께, 열전도율, **화재 등급(준불연)**, 부착 방식 |
| Meldorfer | 규격(가로×세로×두께), 중량, 시공 가능 바탕, 흡수율 |

## 2. 필드 그룹 `색상`

**위치 규칙**: `게시물 유형` **같음** `색상`

| 필드 레이블 | 필드 명 | 필드 유형 | 비고 |
|---|---|---|---|
| 색상 번호 | `color_code` | 텍스트 | 예: `Caparol 3D 15` |
| 색상 값 | `color_hex` | 컬러 피커 | 화면에 칩으로 표시됨 |
| 비고 | `color_note` | 텍스트 | 예: 외부 전용 |

> 색상 글의 **제목**에는 색상명을, 색상번호는 `color_code` 에 따로 넣으세요.

---

## 3. 필드 그룹 `시공사례 정보`

**위치 규칙**: `게시물 유형` **같음** `시공사례`

| 필드 레이블 | 필드 명 | 필드 유형 | 비고 |
|---|---|---|---|
| 위치 | `location` | 텍스트 | 시/군까지. 예: 경기 양평군 |
| 준공 연도 | `year` | 숫자 | |
| 시공 면적 | `area` | 텍스트 | 예: 320㎡ |
| 사용 제품 | `used_products` | 관계 | 포스트 타입 필터: 제품 ★ |

> 사진은 본문의 **갤러리 블록**으로 넣으세요.
>
> `used_products` 가 중요합니다. 사례 → 제품으로 링크가 생기고,
> 제품 페이지에서 "이 제품 시공사례"를 모을 수 있습니다.
> 내부 링크가 촘촘해지면 검색 노출에도 유리합니다.

## 4. 필드 그룹 `기술자료`

**위치 규칙**: `게시물 유형` **같음** `기술자료`

| 필드 레이블 | 필드 명 | 필드 유형 | 비고 |
|---|---|---|---|
| 파일 | `file` | 파일 | PDF |
| 설명 | `doc_note` | 텍스트 | |
| 유효기간 | `valid_until` | 날짜 선택 | **시험성적서용** |

> 시험성적서는 유효기간이 있습니다. 만료된 성적서가 걸려 있으면 설계사에게 신뢰를 잃습니다.
> 날짜를 넣어두면 **기술자료 목록 화면에 만료 여부가 자동 표시**됩니다
> (만료: 빨강 / 60일 이내: 주황).

## 만든 뒤 확인

- [ ] 필드 그룹을 **게시**했다 (오른쪽 위 버튼)
- [ ] **제품 → 새로 추가** 에 위 입력 칸들이 보인다
- [ ] 제품 1개를 시험 입력 — 기술 데이터 3줄, 특징 2줄
- [ ] 발행 후 앞화면에서 표가 제대로 그려지는지 확인
      (아직 템플릿이 없으면 본문에 `[caparol_specs]` 를 직접 넣어 테스트)
- [ ] 슬러그를 **영문**으로 바꿨다 (예: `amphibolin`) ← 한글 주소는 공유 시 깨집니다

여기까지 되면 **Elementor 테마 빌더로 제품 상세 템플릿**을 만들 차례입니다.

---

## 나중에 ACF PRO로 올린다면

제품이 수십 개로 늘고 여러 명이 관리하게 되면 PRO의 반복 필드가 편합니다.
그때는 `specs` 텍스트영역의 내용을 반복 필드로 옮기고,
`functions.php` 의 `caparol_specs_table()` 만 바꾸면 됩니다.
**입력해둔 데이터는 버리지 않아도 됩니다.**
