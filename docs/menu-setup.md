# 메뉴 정리

작성 2026-08-26 · 화면: 워드프레스 관리자 `외모` → `메뉴`

---

## 0. 먼저 알아둘 것

**헤더는 Elementor로 만들었지만, 메뉴 항목은 워드프레스에서 관리합니다.**
Elementor 헤더의 메뉴 위젯이 워드프레스 메뉴를 그대로 가져다 그립니다.
그래서 아래 작업만 하면 헤더가 알아서 바뀝니다. Elementor를 열 필요가 없습니다.

**`문의하기` 는 메뉴에 넣지 마세요.**
Elementor 헤더의 초록 버튼이 이미 그 역할을 합니다. 메뉴에도 넣으면 두 번 나옵니다.

**`컬러` 는 아직 넣지 마세요.**
`/colors/` 화면을 아직 안 만들었습니다. 메뉴에 넣으면 워드프레스 기본 화면이 나와서
디자인이 깨진 페이지를 방문자가 보게 됩니다. 색상 데이터가 준비되고 화면을 만든 뒤에 넣습니다.

---

## 1. 최종 구조

```
브랜드
제품 ▾
 ├ 프라이머
 ├ 페인트
 ├ 플라스터 / 퍼티
 ├ 유리직물벽지
 ├ 장식 인테리어
 ├ 외단열시스템
 └ Meldorfer 벽돌마감
시공사례 ▾
 ├ 국내
 └ 해외
기술자료 ▾
 ├ 시험성적서 · 인증서
 ├ 카탈로그
 ├ 기술자료 (TDS)
 └ 시공지침
```

최상위 **4개**. (컬러를 나중에 넣으면 5개)

---

## 2. 최상위 4개 만들기

`외모` → `메뉴` 에서 편집할 메뉴를 고릅니다. 없으면 `새 메뉴 만들기` → 이름 `주메뉴`.

왼쪽 상자 중 **`사용자 정의 링크`** 를 펼치고, 아래 4개를 하나씩 추가합니다.
(`URL` 과 `링크 문구` 를 넣고 `메뉴에 추가`)

| URL | 링크 문구 |
|---|---|
| `/about/` | 브랜드 |
| `/products/` | 제품 |
| `/references/` | 시공사례 |
| `/downloads/` | 기술자료 |

> **왜 `페이지` 상자에서 고르지 않나요?**
> 제품·시공사례·기술자료는 페이지가 아니라 목록 화면이라 `페이지` 상자에 나오지 않습니다.
> `브랜드` 만은 `페이지` 상자에서 골라도 됩니다. 결과는 같습니다.

> **URL 을 `/products/` 처럼 짧게 적는 이유**
> 나중에 `caparol.kr` 로 주소를 옮길 때 링크를 고칠 필요가 없습니다.
> 만약 저장했더니 `http:///products/` 처럼 이상하게 바뀌면
> 전체 주소(`https://caparol.mycafe24.com/products/`)로 넣으세요.
> 그 경우 도메인 이전 때 이 4줄만 고치면 됩니다.

추가한 4개를 드래그해서 **브랜드 → 제품 → 시공사례 → 기술자료** 순서로 맞춥니다.

---

## 3. 하위 항목 넣기

### 제품 아래 — 카테고리 7개

왼쪽 **`제품 카테고리`** 상자 → `전체 보기` 탭 → 7개 모두 체크 → `메뉴에 추가`

오른쪽 목록 맨 아래에 7개가 붙습니다. 이걸 **`제품` 바로 아래로 드래그**하고,
**오른쪽으로 살짝 밀어서** 들여쓰기 합니다. `하위 항목` 이라고 표시되면 성공입니다.

순서는 이렇게 맞춰주세요 (자료 흐름 순):

```
프라이머 → 페인트 → 플라스터 / 퍼티 → 유리직물벽지
→ 장식 인테리어 → 외단열시스템 → Meldorfer 벽돌마감
```

### 시공사례 아래 — 지역 2개

왼쪽 **`지역`** 상자 → `국내`, `해외` 체크 → 추가 → `시공사례` 아래로 들여쓰기

### 기술자료 아래 — 자료 구분 4개

왼쪽 **`자료 구분`** 상자 → 4개 체크 → 추가 → `기술자료` 아래로 들여쓰기

순서: **시험성적서 · 인증서 → 카탈로그 → 기술자료 (TDS) → 시공지침**
시험성적서를 맨 위에 둡니다. 설계사가 가장 먼저 찾는 자료입니다.

---

## 4. 저장

화면 아래 `메뉴 저장`.

`메뉴 설정` 의 **`새 최상위 페이지 자동 추가`** 는 **체크 해제**하세요.
체크되어 있으면 페이지를 만들 때마다 메뉴에 제멋대로 끼어듭니다.

---

## 5. 확인

실제 사이트를 새 창에서 열고 (관리자 로그아웃 상태나 시크릿 창 권장):

- [ ] 최상위 4개가 한 줄에 들어간다
- [ ] `제품` 에 마우스를 올리면 7개가 펼쳐진다
- [ ] 각 항목을 눌렀을 때 404 가 아니다
- [ ] 모바일에서 햄버거를 누르면 하위 항목이 접혔다 펴진다
- [ ] `문의하기` 가 **한 번만** 나온다

---

## 6. 안 될 때

| 증상 | 원인 · 해결 |
|---|---|
| 헤더가 안 바뀐다 | Elementor 메뉴 위젯이 다른 메뉴를 보고 있습니다. 헤더 편집 → 메뉴 위젯 선택 → `메뉴` 항목에서 `주메뉴` 선택 |
| 여전히 안 바뀐다 | `설정` → `WP Super Cache` → `캐시 삭제`. 브라우저도 `Ctrl+F5` |
| 링크가 404 | `설정` → `고유주소` → 아무것도 바꾸지 말고 `변경사항 저장` |
| 하위 항목이 안 들어간다 | 드래그가 어렵습니다. 항목을 펼쳐 `이동` 링크 → `아래 (하위 항목)` 을 눌러도 됩니다 |
| 왼쪽에 분류 상자가 없다 | 화면 오른쪽 위 `화면 옵션` 을 열어 해당 상자를 체크 |

## 나중에 추가할 것

- **컬러** — `/colors/` 화면을 만든 뒤 `사용자 정의 링크` 로 추가 (제품과 시공사례 사이)
- **공지사항** — 푸터에만 두는 것을 권합니다. 최상위 메뉴는 5개를 넘기지 않는 편이 좋습니다
