# 메뉴 정리

작성 2026-08-26 · 화면: 워드프레스 관리자 `외모` → `메뉴`

---

## 0. 먼저 알아둘 것

**헤더는 Elementor로 만들었지만, 메뉴 항목은 워드프레스에서 관리합니다.**
Elementor 헤더의 메뉴 위젯이 워드프레스 메뉴를 그대로 가져다 그립니다.
그래서 아래 작업만 하면 헤더가 알아서 바뀝니다. Elementor를 열 필요가 없습니다.

**`문의하기` 는 메뉴에 넣지 마세요.**
Elementor 헤더의 초록 버튼이 이미 그 역할을 합니다. 메뉴에도 넣으면 두 번 나옵니다.

**`컬러` 는 아직 넣지 마세요.**
`/colors/` 화면을 아직 안 만들었습니다. 메뉴에 넣으면 워드프레스 기본 화면이 나와서
디자인이 깨진 페이지를 방문자가 보게 됩니다. 색상 데이터가 준비되고 화면을 만든 뒤에 넣습니다.

```
시공사례 ▾
 ├ 국내
 └ 해외
기술자료 ▾
 ├ 시험성적서 · 인증서

 ├ 기술자료 (TDS)
 └ 시공지침
```

최상위 **4개**. (컬러를 나중에 넣으면 5개)

---

## 2. 넣는 순서가 중요합니다

메뉴 항목은 **항상 목록 맨 아래에 추가됩니다.**
최상위 4개를 먼저 다 만들고 나중에 하위 11개를 붙이면, 그 11개가 전부 맨 아래에 쌓여서
위로 끌어올려야 합니다. 드래그가 많아지고 자꾸 엉뚱한 자리에 떨어집니다.

**부모 하나 → 그 자식들 → 다음 부모 → 그 자식들** 순으로 넣으세요.
자식이 항상 부모 바로 아래에 떨어지므로 **오른쪽으로 미는 것만** 하면 됩니다.

### 화면 구성

`외모` → `메뉴` 는 좌우로 나뉩니다.

```
┌─ 왼쪽: 메뉴 항목 추가 ────┬─ 오른쪽: 메뉴 구조 ──────────────┐
│ ▸ 페이지                 │  메뉴 이름: [ 주메뉴        ]     │
│ ▸ 글                     │                                  │
│ ▸ 사용자 정의 링크        │  ┌──────────────────────┐        │
│ ▸ 카테고리               │  │ 브랜드    사용자 정의 링크 ▾│    │
│ ▸ 제품 카테고리          │  ├──────────────────────┤        │
│ ▸ 지역                   │  │   ㄴ 프라이머   제품 카테고리 ▾│  │
│ ▸ 건물 용도              │  └──────────────────────┘        │
│ ▸ 자료 구분              │                                  │
│ ▸ 색상 계열              │  메뉴 설정                        │
│                          │  [ 메뉴 저장 ]                    │
└──────────────────────────┴──────────────────────────────────┘
```

왼쪽 상자가 안 보이면 화면 **오른쪽 맨 위 `화면 옵션`** 을 펼쳐 체크하세요.
메뉴가 없으면 `새 메뉴 만들기` → 이름 `주메뉴` → `메뉴 만들기`.

## 3. 순서대로 넣기

### ① 브랜드
왼쪽 `사용자 정의 링크` 펼치기 → URL `/about/` · 링크 문구 `브랜드` → `메뉴에 추가`

### ② 제품
같은 상자에서 → URL `/products/` · 링크 문구 `제품` → `메뉴에 추가`

### ③ 제품 하위 7개
왼쪽 `제품 카테고리` 펼치기 → **`전체 보기` 탭** (기본은 `최근` 탭이라 일부만 보입니다)
→ 7개 모두 체크 → `메뉴에 추가`

`제품` **바로 아래**에 붙습니다. 이제 들여쓰기만 하면 됩니다.

> **방법 A — 드래그**: 항목을 잡고 오른쪽으로 30px 정도 밀면 `하위 항목` 이라고 표시됩니다.
> **방법 B — 권장**: 항목 오른쪽 `▾` 를 펼치면 맨 아래 `이동` 줄이 있습니다.
> `하위로` (또는 `아래 (제품의 하위 항목)`) 를 클릭하면 한 칸 들어갑니다. 훨씬 정확합니다.

순서는 시공 흐름대로 맞춰주세요:
`프라이머 → 페인트 → 플라스터 / 퍼티 → 유리직물벽지 → 장식 인테리어 → 외단열시스템 → Meldorfer 벽돌마감`
(`▾` → `이동` → `위로` / `아래로`)

### ④ 시공사례
`사용자 정의 링크` → URL `/references/` · 문구 `시공사례` → `메뉴에 추가`

### ⑤ 시공사례 하위 2개
왼쪽 `지역` → `전체 보기` → `국내`, `해외` 체크 → 추가 → 오른쪽으로 밀기

### ⑥ 기술자료
`사용자 정의 링크` → URL `/downloads/` · 문구 `기술자료` → `메뉴에 추가`

### ⑦ 기술자료 하위 4개
왼쪽 `자료 구분` → `전체 보기` → 4개 체크 → 추가 → 오른쪽으로 밀기
**`시험성적서 · 인증서` 를 맨 위로.**

## 3-b. 완성 모습

```
브랜드                    사용자 정의 링크
제품                      사용자 정의 링크
  ㄴ 프라이머              제품 카테고리
  ㄴ 페인트                제품 카테고리
  ㄴ 플라스터 / 퍼티        제품 카테고리
  ㄴ 유리직물벽지           제품 카테고리
  ㄴ 장식 인테리어          제품 카테고리
  ㄴ 외단열시스템           제품 카테고리
  ㄴ Meldorfer 벽돌마감     제품 카테고리
시공사례                   사용자 정의 링크
  ㄴ 국내                  지역
  ㄴ 해외                  지역
기술자료                   사용자 정의 링크
  ㄴ 시험성적서 · 인증서     자료 구분
  ㄴ 카탈로그               자료 구분
  ㄴ 기술자료 (TDS)         자료 구분
  ㄴ 시공지침               자료 구분
```

총 15줄, 최상위 4개.

> **URL 을 `/products/` 처럼 짧게 적는 이유**
> 나중에 `caparol.kr` 로 옮길 때 링크를 고칠 필요가 없습니다.
> 저장했더니 `http:///products/` 처럼 이상해지면 전체 주소
> (`https://caparol.mycafe24.com/products/`)로 넣으세요. 그 경우 도메인 이전 때 4줄만 고치면 됩니다.

## 4. 저장

화면 아래 `메뉴 저장`.

`메뉴 설정` 의 **`새 최상위 페이지 자동 추가`** 는 **체크 해제**하세요.
체크되어 있으면 페이지를 만들 때마다 메뉴에 제멋대로 끼어듭니다.

---

## 5. 확인

시크릿 창(`Ctrl+Shift+N`)으로 사이트를 엽니다.
로그인 상태면 관리자 바 때문에 헤더가 달라 보입니다.

- [ ] 최상위 4개가 한 줄에 들어간다
- [ ] `제품` 에 마우스를 올리면 7개가 펼쳐진다
- [ ] 각 항목을 눌렀을 때 404 가 아니다
- [ ] 모바일에서 햄버거를 누르면 하위 항목이 접혔다 펴진다
- [ ] `문의하기` 가 **한 번만** 나온다

## 6. 안 될 때

| 증상 | 원인 · 해결 |
|---|---|
| 헤더가 안 바뀐다 | Elementor 헤더 편집 → **메뉴 위젯 클릭** → 왼쪽 `내용` 탭 → `메뉴` 에서 **`주메뉴`** 선택 → 업데이트 |
| 여전히 안 바뀐다 | `설정` → `WP Super Cache` → `캐시 삭제`. 브라우저도 `Ctrl+F5` |
| 링크가 404 | `설정` → `고유주소` → 아무것도 바꾸지 말고 `변경사항 저장` |
| 하위 항목이 안 들어간다 | 드래그 대신 `▾` → `이동` → `하위로` 를 쓰세요 |
| 드래그가 자꾸 엉뚱한 데로 간다 | 같은 방법(`▾` → `이동`)을 쓰세요. 훨씬 정확합니다 |
| `전체 보기` 탭에 카테고리가 없다 | mu-plugins 가 안 올라갔을 수 있습니다. `제품` → `제품 카테고리` 에 7개가 보이는지 먼저 확인 |
| 왼쪽에 분류 상자가 없다 | 화면 오른쪽 위 `화면 옵션` 을 열어 해당 상자를 체크 |

## 나중에 추가할 것

- **컬러** — `/colors/` 화면을 만든 뒤 `사용자 정의 링크` 로 추가 (제품과 시공사례 사이)
- **공지사항** — 푸터에만 두는 것을 권합니다. 최상위 메뉴는 5개를 넘기지 않는 편이 좋습니다
