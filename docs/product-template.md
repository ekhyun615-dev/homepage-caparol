# 제품 상세 템플릿 만들기 (Elementor 테마 빌더)

**이 프로젝트에서 가장 중요한 작업입니다.**

여기서 만든 디자인 하나가 앞으로 등록할 **모든 제품에 자동 적용**됩니다.
제품이 50개가 되어도 직원은 내용만 채우면 되고, 디자인을 바꿀 때도 이 템플릿 하나만 고치면 됩니다.

> 반나절 정도 걸립니다. 한 번에 완벽하게 만들려 하지 말고, **골격부터 세우고 나중에 다듬으세요.**

---

## 0. 시작 전 확인

- [ ] Elementor **Pro** 활성화 (무료판에는 테마 빌더가 없습니다)
- [ ] 제품이 최소 1개 등록되어 있음 (미리보기용)
- [ ] 자식 테마 `Caparol Korea` 활성화

---

## 1. 템플릿 만들기

**템플릿 → 테마 빌더** (Templates → Theme Builder)

1. 왼쪽 목록에서 **단일 게시물**(Single Post) 선택
2. **+** 또는 `새로 추가` 클릭
3. 템플릿 이름: `제품 상세`
4. 라이브러리 팝업이 뜨면 **닫기** — 남의 템플릿을 가져오면 정리하는 데 더 오래 걸립니다

빈 캔버스에서 시작합니다.

## 2. 미리보기 대상 지정

빈 화면이라 뭘 만드는지 안 보입니다. 먼저 미리볼 제품을 지정하세요.

화면 아래 **설정(톱니) → 미리보기 설정** → `제품` → `암피볼린` → **적용 & 미리보기**

이제 실제 데이터가 보이는 상태로 작업합니다.

---

## 3. 레이아웃 — 위에서부터

`docs/ia.md` §4의 제품 상세 설계를 따릅니다.

```
┌──────────────────────┬───────────────────────────────┐
│                      │  제품명            (게시물 제목)│
│    특성 이미지         │  한 줄 요약        (summary)   │
│                      │  용도 · 적용 부위   (usage)     │
│                      │  [ 견적 문의 ]  [ 샘플 신청 ]   │
└──────────────────────┴───────────────────────────────┘
  주요 특징        [caparol_features]
  기술 데이터      [caparol_specs]
  관련 자료        (documents)
  ───────────────────────────────────────────────────
  문의 CTA
```

### 3-1. 상단 — 2열 컨테이너

1. **+** 로 컨테이너 추가 → 방향 **가로**, 열 2개
2. 왼쪽 열: **특성 이미지**(Featured Image) 위젯
3. 오른쪽 열에 순서대로:
   - **게시물 제목**(Post Title) 위젯
   - **텍스트 편집기**(Text Editor) 위젯 → 한 줄 요약 연결 (아래 §4)
   - **텍스트 편집기** 위젯 → 용도·적용 부위 연결
   - **버튼**(Button) 위젯 2개 → `견적 문의` / `샘플 신청`
4. 모바일에서는 **세로 1열**로 바뀌게 (반응형 탭에서 확인)

### 3-2. 주요 특징

1. **제목**(Heading) 위젯 → `주요 특징`
   - 고급 → CSS 클래스에 `caparol-heading` 입력 (브랜드 그린 밑줄이 붙습니다)
2. **단축코드**(Shortcode) 위젯 → 내용에 `[caparol_features]`

### 3-3. 기술 데이터

1. **제목** 위젯 → `기술 데이터` (CSS 클래스 `caparol-heading`)
2. **단축코드** 위젯 → `[caparol_specs]`

### 3-4. 관련 자료

1. **제목** 위젯 → `기술자료 다운로드`
2. 관계 필드(`documents`)는 Elementor 기본 위젯으로는 목록 출력이 까다롭습니다.
   **1차 오픈에서는 생략**하고, 기술자료 페이지로 가는 **버튼** 하나만 두세요.
   나중에 필요하면 전용 단축코드를 추가하겠습니다.

### 3-5. 문의 CTA

- 배경을 `#96c11c` 로 채운 컨테이너
- 안에 **제목** + **버튼**(문의하기)
- ⚠️ 초록 배경 위 글자는 **검정**으로. 흰 글자는 대비가 부족합니다 (`brand/README.md` 참고)

## 4. ACF 필드 연결 — 동적 태그

`summary`, `usage` 같은 필드는 위젯에 직접 타이핑하지 않고 **동적 태그**로 연결합니다.
그래야 제품마다 다른 값이 자동으로 들어갑니다.

1. **텍스트 편집기** 위젯 선택
2. 내용 입력창 오른쪽 위의 **원통 모양 아이콘**(동적 태그) 클릭
3. 목록에서 **ACF 필드** 선택
4. `키` 드롭다운에서 필드 선택 — `한 줄 요약`, `용도 · 적용 부위`

> 동적 태그가 안 보이면 Elementor Pro가 비활성이거나 ACF가 꺼져 있습니다.

### 단축코드는 동적 태그가 아닙니다

`[caparol_specs]` / `[caparol_features]` 는 **단축코드 위젯에 그대로 타이핑**하세요.
코드가 알아서 해당 제품의 값을 읽어옵니다.

---

## 5. 표시 조건 — 가장 중요

이걸 안 하면 템플릿이 아무 데도 적용되지 않습니다.

1. 오른쪽 아래 **게시**(Publish) 클릭
2. **표시 조건**(Display Conditions) 창이 뜹니다
3. `포함` → **제품**(Product) 전체 선택
4. **저장 & 닫기**

> 조건을 `전체 사이트`로 두면 안 됩니다. 제품에만 적용해야 합니다.

- [ ] 본문에 넣어둔 단축코드가 **중복으로 두 번** 나오면 → 제품 편집 화면에서 본문의 단축코드를 지우세요
- [ ] **모바일 화면**에서 2열이 1열로 접힌다
- [ ] 제품을 하나 더 만들어서 **같은 디자인으로 나오는지** 확인 ← 템플릿의 존재 이유

## 자주 막히는 곳

| 증상 | 원인 |
|---|---|
| 테마 빌더 메뉴가 없다 | Elementor **Pro** 비활성 |
| 동적 태그 아이콘이 안 보인다 | Elementor Pro 또는 ACF 비활성 |
| 미리보기가 빈 화면 | 미리보기 설정에서 제품을 안 골랐음 |
| 템플릿이 적용 안 됨 | 표시 조건 미설정 (§5) |
| 규격표가 두 번 나옴 | 본문에도 단축코드가 남아 있음 |
| 제목이 두 번 나옴 | 템플릿에 제목 위젯이 두 개이거나, Astra 제목이 켜져 있음 |
| 저장했는데 앞화면이 그대로 | 상단바 **캐시 삭제** |
