# 워드프레스 시작하기 — 처음부터 따라하기

워드프레스를 처음 다루신다는 전제로 썼습니다. **위에서부터 순서대로** 하시면 됩니다.
막히면 맨 아래 "자주 막히는 곳"을 보세요.

---

## 큰 그림 먼저

```
① 내 컴퓨터에 워드프레스 설치  →  ② 여기서 다 만든다  →  ③ 완성되면 서버로 옮긴다
   (LocalWP, 무료)                  (몇 주 걸림)            (카페24 등)
```

**처음부터 실서버에서 만들지 마세요.** 미완성 페이지가 검색엔진에 잡히고,
실수하면 되돌릴 수 없습니다. 내 컴퓨터에서는 뭘 부숴도 괜찮습니다.

준비물: 이 저장소 파일들, 인터넷, 1~2시간.

---

## 1단계 · 내 컴퓨터에 워드프레스 깔기 (20분)

### 1-1. LocalWP 내려받기

https://localwp.com → `Download` → 본인 OS 선택 → 설치

> 이메일을 물어보면 넣어도 되고, `Skip`이 있으면 건너뛰어도 됩니다. 무료입니다.

### 1-2. 사이트 만들기

LocalWP를 켜고 왼쪽 아래 **`+`** (Create a new site) 클릭.

| 물어보는 것 | 넣을 값 |
|---|---|
| Site name | `caparol` |
| 환경 선택 | **Preferred** (그냥 기본값) |
| WordPress username | 원하는 아이디 — ⚠️ **`admin` 은 쓰지 마세요** |
| WordPress password | 아무거나 (내 컴퓨터용이라 간단해도 됨) |
| WordPress email | 본인 이메일 |

만들어지는 데 2~3분 걸립니다.

### 1-3. 들어가보기

사이트가 만들어지면 오른쪽 위에 버튼 두 개가 보입니다.

- **`WP Admin`** → 관리자 화면 (여기서 작업합니다)
- **`Open site`** → 방문자가 보는 화면

`WP Admin` 눌러서 아까 만든 아이디/비밀번호로 로그인하세요.
**이 화면이 앞으로 몇 주간 작업할 곳입니다.**

---

## 2단계 · 기본 설정 (10분)

테마를 깔기 **전에** 먼저 해야 합니다. 특히 고유주소는 나중에 바꾸면 주소가 전부 깨집니다.

왼쪽 메뉴 **설정** 아래를 차례로:

| 메뉴 | 할 일 |
|---|---|
| **설정 → 일반** | 사이트 제목 `카파롤 코리아` / 태그라인 작성 (기본값 "또 하나의 워드프레스 사이트" 꼭 지우기) / 시간대 **서울** |
| **설정 → 고유주소** | **글 이름** 선택 → 저장 ⚠️ **가장 먼저** |
| **설정 → 토론** | "새 글에 댓글 허용" **체크 해제** (스팸의 90%가 여기로 들어옵니다) |
| **설정 → 읽기** | "검색 엔진 노출 방지" **체크** ← 만드는 동안 켜둠. **오픈할 때 반드시 해제** |

---

## 3단계 · 테마 깔기 (15분)

> ⚠️ **Astra의 "몇 분 안에 완성되는 웹사이트 - 지금 구축 시작" 배너를 누르지 마세요.**
> 스타터 템플릿(Starter Templates)을 설치·임포트하는 버튼입니다.
> 남의 업종 더미 콘텐츠(가짜 페이지·이미지·메뉴)가 통째로 들어와서
> 우리가 설계한 구조와 섞이고, 지우는 데 오히려 시간이 더 걸립니다.
> 배너는 오른쪽 위 **×** 로 닫으세요.

### 3-1. Astra 설치

**모양 → 테마 → 새로 추가** → 검색창에 `Astra` → **설치** → **활성화**

### 3-2. 자식 테마 넣기

이 저장소의 `theme/caparol-child/` 폴더를 통째로 넣습니다.

**폴더 여는 법**: LocalWP에서 사이트 이름 옆의 **`Go to site folder`** (또는 폴더 아이콘) 클릭 →
`app` → `public` → `wp-content` → `themes` 로 들어갑니다.

여기에 `caparol-child` 폴더를 **복사해 넣으세요.**

```
wp-content/themes/
├─ astra/            ← 방금 설치된 부모 테마
└─ caparol-child/    ← 여기에 복사
   ├─ style.css
   ├─ functions.php
   └─ acf-json/
```

### 3-3. 자식 테마 활성화

**모양 → 테마** 로 돌아가면 `Caparol Korea` 가 보입니다. **활성화**.

> **왜 자식 테마를 쓰나**: Astra는 계속 업데이트됩니다. Astra를 직접 고치면
> 업데이트할 때마다 고친 게 전부 사라집니다. 자식 테마에 넣으면 안전합니다.

## 4단계 · 사이트 뼈대 넣기 (10분)

제품·시공사례·색상·기술자료 구조를 만드는 코드입니다.

3-2와 같은 방법으로 `wp-content` 폴더까지 갑니다. 거기에 **`mu-plugins`** 폴더가
없으면 **직접 만드세요.** 그 안에 이 저장소 `mu-plugins/` 의 내용을 복사합니다.

```
wp-content/mu-plugins/
├─ caparol-core-loader.php
└─ caparol-core/
   ├─ caparol-core.php
   └─ inc/
```

### 서버(카페24 등)에서 작업하는 경우

LocalWP가 아니라 서버에 직접 설치했다면 **FTP 또는 카페24 파일매니저**로 올립니다.

1. 카페24 호스팅 관리 → **파일매니저** (또는 FileZilla로 FTP 접속)
2. 웹 루트(보통 `/www`) → `wp-content` 로 이동
3. `mu-plugins` 폴더가 없으면 **직접 생성**
4. 그 안에 `caparol-core-loader.php` 와 `caparol-core` 폴더를 업로드

```
/www/wp-content/mu-plugins/
├─ caparol-core-loader.php
└─ caparol-core/
   ├─ caparol-core.php
   └─ inc/
      ├─ post-types.php
      ├─ taxonomies.php
      └─ security.php
```

> ⚠️ **폴더 구조를 그대로 유지**하세요. `inc` 안의 파일들을 밖으로 꺼내면 동작하지 않습니다.
> 파일매니저에서 zip을 올려 압축 해제하는 방법이 실수가 적습니다.

### 확인

관리자 화면을 새로고침하면 왼쪽 메뉴에 이것들이 새로 생겨야 합니다.

**제품 · 시공사례 · 색상 · 기술자료**

그리고 **제품 → 제품 카테고리** 에 들어가면 7개가 자동으로 만들어져 있습니다.
(프라이머 / 페인트 / 플라스터·퍼티 / 유리직물벽지 / 장식 인테리어 / 외단열시스템 / Meldorfer)

> ⚠️ **여기서 한 번 더**: **설정 → 고유주소** 에 들어가서 아무것도 안 바꾸고 **저장**만 누르세요.
> 이걸 안 하면 제품 페이지가 404가 납니다. 워드프레스의 오래된 특성입니다.

## 5단계 · 플러그인 깔기 (15분)

**플러그인 → 새로 추가** 에서 검색해서 설치·활성화합니다.

| 플러그인 | 검색어 | 용도 |
|---|---|---|
| Elementor | `Elementor` | 페이지 만들기 |
| **Elementor Pro** | (유료 — 아래 참고) | 제품 템플릿 · 메가메뉴 |
| Advanced Custom Fields | `ACF` | 제품 규격표 등 |
| Rank Math SEO | `Rank Math` | 검색 최적화 |
| Wordfence | `Wordfence` | 보안 |
| UpdraftPlus | `UpdraftPlus` | 백업 |
| Contact Form 7 | `Contact Form 7` | 문의 폼 |
| Converter for Media | `Converter for Media` | 이미지 WebP 변환 |
| WPS Hide Login | `WPS Hide Login` | 로그인 주소 변경 |

> **내 컴퓨터에서 연습하는 동안에는** Wordfence·UpdraftPlus·WPS Hide Login은
> 나중에 깔아도 됩니다. 실서버 옮길 때 필요합니다.

**설치하지 말 것**: 방문자 카운터, 슬라이더 전용 플러그인, 올인원 마케팅 번들,
출처가 불분명한 한글 플러그인. 플러그인 개수 = 보안 위험 + 속도 저하입니다.

## 6단계 · Elementor 익히기 (30분)

**페이지 → 새로 추가** → 제목에 `연습` 입력 → **`Elementor로 편집`** 버튼 클릭.

왼쪽에 위젯 목록, 오른쪽이 실제 페이지입니다. **끌어다 놓으면** 됩니다.

처음 30분은 그냥 이것저것 만져보세요. 망가뜨려도 됩니다 —
이 `연습` 페이지는 나중에 지우면 그만입니다.

익혀야 할 것 세 가지:

1. **섹션 / 컨테이너** — 가로 한 줄. 이 안에 위젯을 넣습니다
2. **위젯** — 제목, 텍스트, 이미지, 버튼 등
3. **왼쪽 패널의 3개 탭** — `내용`(무슨 글자) / `스타일`(색·크기) / `고급`(여백)

> 색을 지정할 때는 매번 색상표에서 고르지 말고
> **사이트 설정 → 전역 색상** 에 `#96c11c` 를 등록해두고 쓰세요.
> 나중에 색을 바꿀 때 한 곳만 고치면 됩니다.

## 7단계 · 로고와 파비콘 넣기 (15분)

### 7-1. 파일 준비

| 용도 | 필요한 것 |
|---|---|
| 헤더 로고 | **배경이 투명한 PNG** (가로 800px 이상) 또는 SVG |
| 파비콘 | 원본 로고 그대로 (512px 이상이면 됨 — 자르기는 워드프레스가 해줍니다) |

> **JPG는 쓰지 마세요.** JPG는 투명 배경을 지원하지 않아서
> 로고 뒤에 **흰 사각형**이 그대로 따라붙습니다. 헤더 배경이 흰색이 아니면 바로 티가 납니다.
> 본사에서 받은 파일이 JPG뿐이면 투명 PNG를 다시 요청하세요.

> **SVG는 기본적으로 업로드가 막혀 있습니다.** 워드프레스가 보안상 차단합니다.
> 지금은 PNG로 시작하고, SVG는 나중에 Elementor의 SVG 업로드 옵션을 켜서 쓰세요.

### 7-2. 로고 등록

**모양 → 사용자 정의하기 → 사이트 아이덴티티**

1. **로고 선택** → 파일 업로드
2. 자르기 화면이 나오면 **`자르지 않기`** (로고는 원본 비율 그대로 써야 합니다)
3. **로고 너비** 슬라이더로 크기 조정 — 로고 높이가 **44~52px** 정도로 보이게
4. `사이트 제목과 태그라인 표시` **체크 해제** (로고에 이미 글자가 있습니다)
5. **게시** 클릭

### 7-3. 파비콘 등록

같은 화면 아래쪽 **사이트 아이콘**.

1. **사이트 아이콘 선택** → 로고 파일 업로드 (같은 파일이어도 됩니다)
2. 자르기 화면에서 **코끼리 부분만** 정사각형으로 잘라냅니다
   - `CAPAROL` 글자는 빼세요. 16px에서 뭉개져 안 보입니다
   - 코끼리 주위에 여백을 조금 남기세요
3. **게시**

브라우저 탭에 코끼리가 나오면 성공입니다. (안 바뀌면 새로고침 `Ctrl+F5`)

### 7-4. 지금 세로형 로고밖에 없다면

세로형은 헤더에 넣으면 헤더가 두꺼워지거나 글자가 안 보입니다
(자세한 이유는 [brand/README.md](../brand/README.md)).

**임시 조치**: 사이트 아이덴티티에 로고를 넣지 말고, `사이트 제목`에 `CAPAROL KOREA` 를
텍스트로 두세요. 가로형 로고가 오면 그때 바꿉니다.

미완성 로고를 억지로 밀어넣는 것보다 텍스트가 낫습니다.

## 자주 막히는 곳

| 증상 | 원인과 해결 |
|---|---|
| **제품 페이지가 404** | 고유주소 저장을 안 함 → **설정 → 고유주소 → 저장** (그냥 저장만) |
| 왼쪽 메뉴에 "제품"이 안 생김 | `mu-plugins` 폴더 위치·철자 확인. `wp-content/mu-plugins/` 가 맞는지 |
| 자식 테마가 목록에 없음 | `style.css` 맨 위 주석이 지워졌거나, 폴더 위치가 `themes/` 가 아님 |
| 자식 테마 활성화했더니 디자인이 깨짐 | Astra(부모)가 설치·존재하는지 확인. 부모를 지우면 안 됩니다 |
| Elementor 편집 화면이 안 열림 | 브라우저 새로고침 → 그래도 안 되면 다른 플러그인 잠시 비활성화 |
| 사이트가 하얗게 뜸 | 방금 넣은 코드/플러그인 문제. `mu-plugins` 폴더 이름을 임시로 바꿔서 원인 확인 |
| 뭘 잘못 눌렀는지 모르겠음 | 내 컴퓨터라 괜찮습니다. 최악의 경우 LocalWP에서 사이트 지우고 다시 만들면 됩니다 |

## 오늘 여기까지 하면 성공

- [ ] LocalWP에서 `caparol` 사이트가 열린다
- [ ] 관리자 화면에 로그인된다
- [ ] 고유주소가 "글 이름"으로 되어 있다
- [ ] 테마가 `Caparol Korea` (자식 테마)로 활성화되어 있다
- [ ] 왼쪽 메뉴에 **제품 / 시공사례 / 색상 / 기술자료** 가 보인다
- [ ] 제품 카테고리 7개가 자동 생성되어 있다
- [ ] Elementor로 연습 페이지를 하나 만들어봤다
- [ ] 브라우저 탭에 파비콘(코끼리)이 보인다

여기까지 되면 뼈대는 끝입니다. 이제부터는 **자료를 채우는 일**입니다
([content-plan.md](content-plan.md) 참고).
