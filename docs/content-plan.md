# 확보해야 할 자료 목록

사이트 구축이 멈추는 이유의 90%는 **자료가 없어서**입니다. 코드보다 이 목록이 먼저입니다.
확보되는 대로 체크하세요.

---

## 1. 브랜드 자산 (본사에서 받아야 함)

- [ ] 로고 원본 — **AI 또는 SVG** (JPG/PNG만 있으면 인쇄·확대 시 깨집니다)
- [ ] 로고 사용 규정 (여백, 최소 크기, 금지 사용례)
- [ ] 브랜드 컬러 HEX 코드
- [ ] 지정 서체 (없으면 국문은 Pretendard 권장)
- [ ] 한국 파트너 표기 규정 — "Caparol Korea" / "카파롤 코리아" 중 무엇을 쓸지, 본사 승인 필요
- [ ] **공식 수입원 표기 문구** 본사 승인 — 예: "독일 Caparol(DAW SE) 한국 공식 수입원"
- [ ] 수입원 계약서상 사용 가능한 명칭·로고 범위 확인
- [ ] 본사 제공 이미지 사용 권한 범위

## 2. 회사 정보 (푸터·문의 페이지에 들어감)

- [ ] 상호 (국문/영문)
- [ ] 대표자명
- [ ] 사업자등록번호
- [ ] 통신판매업 신고번호 (온라인 판매 시)
- [ ] 주소 (본사 / 물류창고 / 쇼룸)
- [ ] 대표전화 · 팩스 · 이메일
- [ ] 카카오톡 채널 URL
- [ ] 영업시간

## 3. 제품 자료 — 제품 1개당

`docs/ia.md` §3에서 확정한 제품마다 아래를 채웁니다. **스프레드시트로 관리하는 걸 권합니다.**

| 항목 | 필수 | 비고 |
|---|---|---|
| 제품명 (원어) | ✓ | 예: Amphibolin |
| 제품명 (국문 표기) | ✓ | 예: 암피볼린 |
| 카테고리 | ✓ | ia.md §3 기준 |
| 한 줄 요약 | ✓ | 검색결과에 노출됨 |
| 용도 · 적용 부위 | ✓ | |
| 주요 특징 3~5개 | ✓ | 한 줄씩 |
| 기술 데이터 | ✓ | 광택 / 희석률 / 소요량 / 건조시간 / 용기규격 / 시공온도 |
| 제품 이미지 (용기 사진) | ✓ | 흰 배경, 가로 1500px 이상 |
| 적용 사진 | ○ | 실제 시공면 클로즈업 |
| TDS (기술자료 PDF) | ✓ | 국문 우선, 없으면 영문/독문 |
| 시공지침 PDF | ○ | |
| MSDS | ○ | 도료는 요청받는 경우가 많음 |

## 4. 컬러 자료 ★

도료 사이트의 핵심입니다. 가장 오래 걸리는 작업이니 먼저 시작하세요.

- [ ] 취급 색상 목록 (색상번호 + 색상명 + HEX/RGB)
- [ ] 전체 색상을 올릴지, 대표 색상만 올릴지 결정
- [ ] 색상집 실물 보유 여부 (샘플 신청 대응용)
- [ ] 색상 오차 안내 문구 검토

> HEX 값이 없으면 색상집을 스캔·촬영해서 추출해야 합니다. 조명 때문에 정확도가 떨어지니
> 본사 디지털 색상 데이터를 받는 게 가장 좋습니다.

## 5. 시공 사례 — 현장 1건당

- [ ] 현장명 (공개 가능한 명칭인지 확인 — 개인주택은 "OO시 단독주택" 형태)
- [ ] 위치 (시/군까지)
- [ ] 건물 용도 (단독주택 / 상가 / 공공 / 산업)
- [ ] 준공 연도
- [ ] **사용 제품** (제품 페이지와 연결됨)
- [ ] 시공 면적
- [ ] 사진 5~10장 — 전경 / 부분 / 디테일
- [ ] 사진 사용 동의 (건축주 또는 시공사)

> creaton.kr은 37건으로 시작했습니다. **최소 10건**은 있어야 사이트가 비어 보이지 않습니다.

## 6. 인증·시험 자료 ★★

설계사가 채택을 결정하는 자료입니다. **다른 무엇보다 우선**입니다.

- [ ] **준불연 시험성적서** (KS F ISO 5660-1 콘칼로리미터법)
- [ ] 실물화재 시험 성적서 (해당 시)
- [ ] 유럽 인증서 (ETA, CE)
- [ ] 친환경 인증 (HB마크, 실내공기질 등)
- [ ] KS 인증 (해당 시)
- [ ] 성적서 유효기간 확인 — **만료된 성적서를 올려두면 신뢰를 잃습니다**

> 근거: [건축법 제52조 · 건축물의 피난·방화구조 등의 기준에 관한 규칙](https://www.law.go.kr/lumLsLinkPop.do?lspttninfSeq=105201&chrClsCd=010202) —
> 외벽 외측 단열재는 준불연 이상이어야 합니다.

## 6-b. 대리점 페이지 자료

직접 수입·판매 구조이므로 유통망 안내가 필요합니다.

- [ ] 취급 조건 (자격 요건, 최소 발주 물량, 보증금 여부)
- [ ] 대리점에 제공하는 지원 내용 (기술교육 / 시공지원 / 샘플·카탈로그 / 판촉물)
- [ ] 공급 구조 도식에 쓸 내용 (본사 → 수입 → 대리점 → 시공)
- [ ] 기존 취급점 목록 (있는 경우 — 상호·지역·연락처, **게재 동의 필요**)

## 7. 사진 촬영이 필요한 것

기존 자료로 안 되는 것들입니다. 예산·일정 확보 필요.

- [ ] 히어로용 시공 전경 3~5장 (고해상도, 가로형)
- [ ] 제품 용기 스튜디오 촬영
- [ ] 색상집 · 샘플 촬영
- [ ] 사무실/쇼룸 (오시는 길용)

## 우선순위

자료를 전부 모으고 시작할 필요는 없습니다. **아래 순서로 확보되는 대로 오픈**하세요.

| 단계 | 필요한 것 | 결과 |
|---|---|---|
| **1차 오픈** | 로고 · 회사정보 · 제품 5개 · 시공사례 5건 · 준불연 성적서 | 사이트 공개 가능 |
| 2차 | 전체 제품 · 시공사례 10건+ · 전체 TDS | 검색 유입 시작 |
| 3차 | 컬러 시스템 · 게시판 · 자료실 | 완성 |

> 완벽하게 만들어서 한 번에 여는 것보다, 1차로 열고 채워나가는 편이 SEO에도 유리합니다.
> 검색엔진은 사이트의 나이와 갱신 빈도를 봅니다.
