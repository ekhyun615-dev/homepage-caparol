# 브랜드 사용 규칙

## 로고

Caparol의 상징인 **코끼리 마크 + CAPAROL 워드마크**(가로선으로 구분된 세로형)입니다.
코끼리는 검정, 그 위를 여섯 가지 색 띠(마젠타 · 시안 · 그린 · 옐로 · 오렌지 · 레드)가 지나갑니다.
붓은 마젠타입니다.

### 이 폴더에 넣을 파일

```
brand/
├─ logo-vertical.svg      세로형 원본 (현재 보유)
├─ logo-horizontal.svg    가로형 ← 본사에 요청 필요 (아래 참고)
├─ logo-white.svg         어두운 배경용 반전 버전 ← 필요
├─ symbol.svg             코끼리만 (파비콘·앱아이콘용)
└─ favicon-512.png        512×512
```

> ⚠️ 저작권 있는 본사 자산입니다. 저장소를 **Private으로 유지**하세요.

## ⚠️ 해결해야 할 것 1 — 가로형 로고가 필요합니다

보유 중인 로고는 **세로형**(코끼리 위 / 글자 아래)입니다.
헤더에 세로형을 넣으면 두 가지 중 하나가 됩니다.

- 헤더가 세로로 두꺼워져 **첫 화면에서 콘텐츠가 밀려남**
- 헤더 높이에 맞춰 줄이면 **CAPAROL 글자가 읽을 수 없을 만큼 작아짐**

**본사에 가로형(코끼리 + 오른쪽 워드마크) 로고를 요청하세요.** 대부분 보유하고 있습니다.
요청할 때 `.ai` 또는 `.svg` 원본으로 받으시고, 함께 요청할 것:

- [ ] 가로형 로고
- [ ] 흰색(반전) 버전 — 어두운 배경·푸터용
- [ ] 로고 사용 규정(CI 매뉴얼) — 최소 크기, 여백, 금지 사용례
- [ ] "한국 공식 수입원" 표기 문구 승인

### 가로형이 올 때까지

헤더에는 **코끼리 심볼만** 쓰고, 그 옆에 `CAPAROL KOREA` 를 텍스트로 배치하세요.
임시 조치이며, 정식 로고가 오면 교체합니다.

> ⚠️ 코끼리에 `KOREA` 를 직접 붙여 **새 로고를 만들지 마세요.**
> 본사 CI 규정 위반입니다. 회사명은 로고와 분리된 텍스트로 표기합니다.

## ⚠️ 해결해야 할 것 2 — 색을 어디까지 쓸 것인가

로고에는 **여섯 가지 색**이 있습니다. 그 색들을 사이트 UI에 가져다 쓰면
화면이 산만해지고 브랜드가 싸 보입니다.

### 규칙

| 색 | 역할 | 쓰는 곳 |
|---|---|---|
| **검정 `#1a1a1a`** | **주색** | 본문, 제목, 헤더/푸터 배경, 로고 |
| **그린 `#96c11c`** | **강조색** | 버튼, 링크 밑줄, 섹션 구분선, 활성 메뉴 |
| 그린(어두움) `#5f7c0b` | 흰 배경 위 글씨·링크 | 대비 확보용 |
| 회색 계열 | 보조 | 표, 구분선, 캡션 |
| 마젠타·시안·옐로·오렌지·레드 | **로고 전용** | ❌ UI에 쓰지 않음 |

로고 자체가 이미 화려합니다. **사이트는 조용해야 로고가 살아납니다.**
독일 본사 사이트도 흰 바탕 + 검정 + 최소한의 강조색으로 갑니다.

> 예외: 제품 카테고리 7종을 색으로 구분하고 싶은 유혹이 생길 수 있습니다.
> 하지 마세요. 아이콘과 이름으로 구분하고 색은 하나로 통일하세요.

## 로고 배경별 사용

| 배경 | 쓸 로고 | 확인 |
|---|---|---|
| 흰색 / 밝은 회색 | 원본(검정) | ✅ 대비 충분 |
| 그린 `#96c11c` | 원본(검정) | ✅ 대비 약 8:1 — 문제없음 |
| 검정 / 진한 회색 (푸터) | **흰색 버전** | ⚠️ 원본은 코끼리가 안 보임 |
| 사진 위 | 흰색 버전 + 어두운 오버레이 | 사진이 밝으면 판독 불가 |

## 파비콘

**코끼리 심볼만** 잘라서 씁니다. 워드마크는 16px에서 뭉개져 안 보입니다.

- 512 × 512 정사각 PNG
- 코끼리 주위에 여백 약간 (꽉 채우지 않기)
- **모양 → 사용자 정의하기 → 사이트 아이덴티티 → 사이트 아이콘** 에서 업로드

색 띠가 있어 작은 크기에서도 알아보기 쉬운, 파비콘으로 아주 좋은 마크입니다.

## 헤더 로고 크기

| 화면 | 로고 높이 |
|---|---|
| 데스크톱 | 44~52px |
| 모바일 | 32~36px |

업로드는 **실제 표시 크기의 2배** 해상도로 하세요 (고해상도 화면 대응).
SVG를 쓰면 크기 걱정이 없어집니다 — 가능하면 SVG로 받으세요.
